# 蒸足分析：日期統一與店長聚焦

## 已實作

- 預設本月，新增本週（週一至週日），今日／本週／本月／自訂共用台灣日期。歷史月份連結仍可用。
- 客流、成交、回流改用精確區間。沿用首次有效正式方案購買規則；續購不重算。多人同行按 attendedPeople ?? people 計人次，名單不虛構未建檔同行者。
- 比較前一段相同日期進度，完整月份比較前一完整月；去年同期另可展開。回流以前一完整期間顧客為母體，註明基準日期及統計中。
- 摘要四項：已收營收、完成服務人次、體驗人次、開卡人數。訂單、退款、分類收入、來源、店長表格保留。
- 數字與顧客明細共用期間計算；名單點開才查詢，使用置中 dialog、50 筆分頁、關閉取消請求。服務與體驗明細同時提供組數、人次。
- 兩張趨勢合併，預設六個月，可切一年；財務指標採營收結構同一口徑；長期趨勢用 Suspense 獨立載入。
- 移除分析頁一小時月快照，避免補登後摘要舊、其他指標新的混合狀態。日期切換防抖、常用篩選預取、返回前景更新、手動更新及最後更新時間。
- 全店／店長 CSV 帶入相同日期，沿用既有匯出權限與唯讀查看阻擋。期間 CSV 與畫面共用查詢。
- 月空間費保留，跨月範圍加總涵蓋月份，明確標示不按日分攤、不能當作期間利潤。
