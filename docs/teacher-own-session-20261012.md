# 教師／教練自行請假與整堂調課

本輪新增獨立權限 `teacher.session.leave`、`teacher.session.reschedule`，不借用既有代學員請假／改期權限。既有教師／教練預設關閉；只有老闆可設定，保留原三項開關。

入口：教師／教練管理 → LINE 與權限；授課人員「我的工作」每堂課 → 自己請假／整堂調課。彈窗先顯示課名、原時段，權威查詢完成後提供正式學員與候補名單，必填原因；僅單堂、未开始、未停課且無報到／點名。調課保持老師、教室、時長、booking/card/term identity，只改時間；多週、換老師／教室與恢復停課維持門市操作。

保存需有效個別授權、本人課程、有效連結與帳號，同門市交易锁內重查；課程／名單／候補 revision 不符拒絕，避免舊確認覆蓋新安排。調課沿用場地／資格、營業時間、老師可用時間、排班與方案效期守門。整堂請假沿用教師停課返還與預留釋放，候補取消；體驗付款與退款規則不變。共用門市異動與既有教練通知機制保留；未新增學員 LINE 外發或批次排程。

一併補正舊授課操作的 StaffPermission 查詢，只有 granted=true 才授權，且交易重查授課帳號 ACTIVE。後台一般授課資料保存不清除這些獨立開關。

## 驗證與限制

- 相關 action／授權／既有教師保存／UI／預覽隔離回歸完成本機測試；TypeScript 與變更檔 ESLint 通過。
- 自行操作 action 測試使用 mock transaction，並非真實隔離資料庫端到端驗收。
- 受影響：音樂／運動教師與教練管理（桌機/iPad），我的工作（手機／LIFF）。1366/1440、1024×768、768×1024、360/390 及窄容器實際 Preview 驗收待完成；jsdom 只驗呈現與授權阻擋，不代表真機。
- 遠端 exact-head CI、隔離 Preview 與已登入保存／失敗保留尚待驗收，不合併正式。無 migration、無正式資料變更。
- 薪資列表摘要、授課細節剩餘跳頁與列表直接切換權限留待後續；本 PR 聚焦獨立自行請假／調課，避免混用權限。

## 開關保存速度修正

開關改走同源 private/no-store JSON receipt，保持後端老闆、門市、交易重查與稽核；正常保存不等待 Server Action 的 RSC 頁面更新，僅本地確認單筆權限。逐筆 upsert 減少資料庫往返。授權快取採 Route Handler 支援的立即失效，不以 stale 授權放行。跨來源／不符門市或教師／權限／值的receipt拒絕；未知結果或版本衝突鎖定至重新整理核對，未確認前不顯示已儲存。調整其他開關等待文案，避免誤稱其他表單未保存。新增 transport/route/未知結果 tests；新版 Preview 速度仍須實測，不承諾所有保存為零等待。
