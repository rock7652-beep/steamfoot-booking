# 美業公開體驗表單優化

## 結果與範圍

公開表單原本需先填姓名、手機及另一組聯絡人資料才能查時段；修正姓名或備註也會清除選好的時間。
改為「服務／技師安排／手機資格／日期時段 → 姓名與聯絡資料／確認」。手機仍先在後端核對每人每項服務的體驗資格，沒有以假姓名或假聯絡資料送出查詢。

- 第一位預設作為聯絡人，勾選「另設聯絡人」才顯示額外欄位。
- 單一服務直接顯示、單人省略序號，同行者按需新增／移除，上限仍為 12 位。
- 技師性別與指定技師整合為一組選擇，未選不自動視為男女皆可；指定技師仍依服務資格及後端排班限制核對。
- 姓名、手機、備註及聯絡人修正保留已選時間；日期、人數、服務、技師條件變更會清除舊可用時段。手機變更會作廢尚在進行的舊查詢，提交時仍重新核對資格。
- 欄位錯誤就地標示，切換步驟及錯誤時管理焦點；過期的查詢結果不覆蓋新結果。
- 標題、店名與體驗限制各集中顯示；公開表單不顯示會員扣次用語，總價改稱「體驗總額」。單人摘要不重複單價與合計。
- 備註收合、個資用途與隱私政策連結、完整時間／服務／安排／金額摘要。
- 成功頁保留摘要、聯絡人及店家地圖／官方 LINE（僅設定有效時顯示），不宣稱通知已送達。
- 不確定的提交結果鎖定草稿並使用相同 payload／requestKey 重試，阻擋同一事件循環內重複送出。

影響 `/beauty-trial/[slug]` 與其 public availability read。所有美業公開體驗表單共用新版；會員及後台表單仍由既有分流處理。
預約提交仍使用原 `submitBeautyTrial`／完整 `partyInput`／`reserveParty`，沒有 migration、權益或交易規則變更。
