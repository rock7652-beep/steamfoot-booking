## 本輪發現並修正

1. 改期成功仍留在舊日期，現在跟隨新日期及該筆預約。
2. 關閉明細仍殘留 bookingId，導致同一通知不能重開，現在清除目標並同步開啟狀態。
3. 從通知前往明細時，關閉通知觸發的背景 Server Action 可能把頁面帶回舊日期；目標導向時略過這次多餘摘要讀取，保留下次開啟與定時更新。
4. 退款失敗訊息在視窗內外重複顯示，現在僅在當前表單顯示，保留輸入內容。
