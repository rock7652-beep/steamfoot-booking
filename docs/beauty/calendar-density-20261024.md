# 班表密度與顧客／店長篩選

在原 CourseWorkspace、CourseScheduleBoard 上提供美業資料與工具列內容，不建立另一套班表。音樂／運動未啟用服務模式時，維持原有篩選、時間格與圖例。

| 原狀況 | 本輪調整 |
| --- | --- |
| 頂部租借快捷鍵、多排篩選、重複日期及圖例說明占用高度 | 移除班表的新增租借、預約清單快捷鍵與重複日期，視角、統計、搜尋、所屬店長與三色圓點集中排列 |
| 全域技師、位置、類型等篩選 | 保留顧客姓名／電話與所屬店長，兩者取交集；清除搜尋不重設店長，日期／視角保留。忽略已移除控制的舊篩選狀態 |
| 搜尋也比對服務名稱 | 只比對授權顧客姓名、電話；電話沿用共用正規化，支援部分電話與格式分隔。無符合結果有明確提示，統計跟著更新 |
| 方形圖例與額外完成／整理說明 | 綠、橘、粉使用同尺寸圓點及文字，移除額外圖例說明；卡片完成與收款仍分開，整理時間斜線保留 |
| 固定時格，桌機須往下捲 | 桌機依實際營業時間、歷史占用及可用高度調整；短卡片分別保留姓名、服務的顯示空間，完整明細可點開 |
| 班表沒有現金收支入口 | 直接傳入既有 CashbookShortcut／QuickCashbook，沿用讀取、寫入及跨店權限；不與現金抽屜混用 |

週表原有的資源瀏覽選擇保留，用來切換顯示的位置或技師，與已移除的全域篩選不同。租借新增改由「位置管理 → 租借紀錄 → 新增租借」，仍使用原 RentalPanel；新增入口需明確授權，其他模組預設不增加此入口。

姓名、電話及店長歸屬由原本授權的美業來源提供；租借電話／顧客 ID 同樣在沒有顧客讀取權限時清空。來源版本包含歸屬與讀取權限，避免重開後沿用舊的篩選資料。此輪不變更預約、收款、拆帳、方案扣次或店長授權規則。
