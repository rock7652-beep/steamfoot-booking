- 美業與相關運動共用功能：39 個測試檔、339 項通過；包含日期預填、草稿切頁／離開、核帳表單、同行分項取消、顧客開關、技師更正、分類 FormData、權限及分析計算。

- Chromium 本機合成資料：20 組斷言，手機360／390、桌機1366×900、iPad1024×768／768×1024；無頁面水平溢出或未處理例外，已看過主要截圖。
- 本機使用實際元件，但替代 Next 導覽、伺服器 actions、圖片載入，**不等於 Next hosted、真後端、真帳本、實體裝置或店家簽收**。沒有實際對外寫入。
