# 共用店家資料 Google Maps 摘要

美業、音樂與運動沿用的 CourseSettingsWorkspace「店家資料」收合列新增 Google Maps：已設定／未設定。有有效 HTTPS 地圖網址時顯示「開啟地圖」，以新分頁開啟並設定 noopener noreferrer；空白、無效或非 HTTPS 的舊值不產生連結。

沿用原有「修改 → 地圖網址」欄位、修訂檢查及儲存後確認狀態，不新增 API、讀取或資料庫操作，也不改店家的實際地址或連結。

共用 SettingsListRow 原有容器換行保留。操作採 44px 最小高度，兩個操作寬度與原 200px 操作欄一致；長摘要可換行。受影響入口為美業設定／店家資料，以及音樂／運動共用設定工作台。桌機 1366／1920、iPad 768／1024 與窄容器的實際瀏覽器尺寸仍待驗收；本輪無瀏覽器操作工具，不以靜態檢查冒充視覺驗收。

3 檔 58 項既有設定、儲存權限與美業 store guard 離線測試通過；TypeScript、ESLint、git diff --check 通過。沒有新增低影響版面測試或執行線上儲存。

依使用者延續授權更新既有隔離 Preview；LINE 關閉、migration 跳過、正式站不動。實際部署結果另存證據。
