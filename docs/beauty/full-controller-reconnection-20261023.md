原模組預設端點保留；有 source 時只透過對應授權端點。業務仍進原美業預約、catalog、帳本與 Store 鎖交易，沒有以建立 CourseBooking／CourseSession 假冒串接。收費方案結帳使用原收款介面，明確選付款方式；預約不會自動收款或扣方案。

## 必要資料保護

- 方案保留與實際扣次分開；「未到」依實際 debit 顯示，不用課程曠課扣堂假設。
- 顧客新增帶穩定請求鍵、店家及建立回條；重送不重建。顧客編輯帶目前修訂，略過的身高／備註欄位不清空既有值。
- 方案結帳核對店家、權威售價、到期日、同店顧客、折抵權限及現金抽屜，保留原 issueCard 冪等交易。
- 原人員儲存核心支援原表單的生日／緊急聯絡人及建立狀態／權限，沿用權限上限、角色層級、最後店主與版本守門。
- 預覽每次 GET 重新授權店家及選取身分；技師不再誤用 Main Staff ID。預覽中的保存、狀態、購買、預約及健康寫入停用，既有預覽寫入阻擋仍保留。
