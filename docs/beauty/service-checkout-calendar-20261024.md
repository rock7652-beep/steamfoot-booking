# 服務完成、收款優惠與班表色塊

本輪沿用原共用班表及 CourseAssignmentPayment 的優惠欄位，抽成同一個 CourseDiscountFields；美業僅提供服務應收及收款接點，不接 SPA，也不建立另一套課程結帳規則。

| 原狀況 | 調整結果 |
| --- | --- |
| 服務完成還要確認及填原因 | 直接完成；伺服器記錄操作者、時間及固定完成原因。取消、未到及恢復更正仍依原規則核對 |
| 收款視窗占滿頁面，直接填金額 | 內容尺寸、桌機最大 560px；共用打折／折抵金額，分列原價、優惠、應收、已收、未收與本次收款，備註收合 |
| 班表預約全白 | 一般綠色、體驗橘色、租借粉色；完成勾選與收款標示分開，整理時間以實際分鐘顯示灰色斜線 |

優惠使用追加式稽核事件；不改寫預約原價、既有收款或方案帳本。實收拆帳依實收，原價拆帳保留原價基準。讀取收款需本店預約及收款權限，優惠另檢查 transaction.discount；過期修訂拒絕、相同請求重送不重複入帳。收款後更新班表來源版本，避免沿用舊的完成或收款標示；運動／音樂未提供此版本時維持原行為。
