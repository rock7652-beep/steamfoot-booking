## 不列為美業獨有退步的觀察

實測服務項目搜尋「做臉」，離開到首頁再返回會清空。美業管理清單與運動一般目錄的搜尋都採元件本機state，因此不能稱為「運動原本有保留、美業退步」。它仍是產品狀態留存可改善項目；同頁編輯開關後保留搜尋已實測正常。運動班表則有獨立的狀態留存能力，須與目錄分開判斷。

## 建議下一步順序

1. 先修H01日期上下文與H02預約草稿保護，避免選錯日與重填。
2. 再接回顧客／技師前台的原導覽、站內確認／核帳、同組預約展收及月份明細；保留美業性別、人數與服務分項規則。
3. 補齊顧客明細、技師管理分類、營運／分析與設定面板的實際操作沿用；共用呈現，交易資料仍取自美業。
4. 再驗有資料的顧客經營、超過20筆分頁與長名稱、實體手機／iPad及店家簽收；LINE完成申請後另驗登入與送達。

本輪不重新跑交易扣次或退款，也沒有新寫入程式，因此不把前輪373項結果當成本輪新增測試；正式啟用仍另行處理。
