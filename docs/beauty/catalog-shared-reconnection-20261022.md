## 實際使用的同一份元件

| 入口 | 共用來源 | 本輪接回的操作 | 美業必要差異 |
| --- | --- | --- | --- |
| 位置管理 | `src/app/(dashboard)/dashboard/courses/workspace.tsx` 的 `CourseWorkspace`、原 `RoomMore` 欄位 | 搜尋、分類／狀態篩選、停用區展開、原清單、原新增／編輯／檢視視窗、儲存／錯誤保留、單筆／批次啟停用 | 仍讀寫 `CourseRoom`，不新增床位資料；不帶入租借、租金及團課容納人數。 |

| 收費方式 | `src/app/(dashboard)/dashboard/courses/member-workspace.tsx` 的 `CourseMemberWorkspace` | 原方案清單、搜尋、狀態／服務／購買方式／共卡篩選、停用區、分頁、原新增／編輯／檢視視窗 | 同列單次、體驗、次數方案；收費類型在同一個表單選擇，沒有另外先開美業類型選擇視窗。 |
| 方案編輯 | `src/app/(dashboard)/dashboard/courses/course-profile-forms.tsx` 的 `CoursePlanDraftForm` | 原草稿保護、錯誤保留、儲存與取消、適用服務選擇、購買方式與共卡設定 | 以次數計算，新增的次數、售價、期限、適用服務均不預設，購買方式預設僅後台；保留家人共用、店家選服務、個別低次數提醒；不帶入運動固定期課／補課與音樂學期／教師分潤欄位。 |

`src/components/beauty/catalog-adapter.tsx` 只做資料轉換與動作接線，沒有另寫清單、卡片、對話框或編輯版型。大型共用工作台以動態載入，避免顧客管理、首頁或技師清單先下載兩套工作台。

美業原 `BeautyChargesList`、`BeautyCatalogEditor` 的位置／服務／方案／價格分支已斷開這些入口；舊檔保留不表示仍在使用，沒有刪除業務資料。技師與設定仍待另批接回，未以本批宣告後台整站完成。

## 資料與交易邊界

- 價格仍使用既有美業欄位，集中由收費方式編輯，沒有新增價格表或資料搬移。修改服務時長／分類時保留單次與體驗價格；修改其中一種價格時保留另一種及服務時長／整理時間。
- 原 `saveBeautyCatalog`、`saveBeautyLocation` 繼續執行店別、權限、功能開關及既有預約影響檢查；服務／方案的既有 revision 檢查保留。共用 UI 不把美業 ID 送進課程寫入動作。
- 儲存回傳同一交易內的已儲存資料，供原工作台立即確認／重開；不依賴稍後整頁刷新才更新值。位置仍使用原本的權限與寫入規則，本輪沒有新增位置 revision 制度。
- 既有卡片、餘額、保留次數、扣次、退款及帳本流程未改動；沒有操作真實資料庫或新增驗收商品。
- 「目前全部服務」在儲存時展開為當下啟用的服務 ID；不將課程空 ID 的「所有未來課程」語意套入美業，也不把新服務自動加進已設定方案。
- 單次／體驗不當成可販售的多次卡。單次啟停跟隨服務項目，體驗留空維持不開放；方案可單筆／批次上下架，失敗項目保留並回報。沒有開放課程的硬刪除操作。
- 拖曳排序的後端接點尚未接回；原先美業沒有此排序儲存流程。本批隱藏這些控制，避免誤呼叫課程排序動作或顯示永遠不能儲存的按鈕。這是待接回項目，沒有宣告不能共用。
