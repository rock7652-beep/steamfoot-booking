# 美業價格與分帳欄位／體驗費用彈性（2026-10-26 台灣）

使用者確認：集中售價、體驗價及店家費用，顯示分帳預覽，允許體驗店家費用獨立設定。沿用既有共用收費表單，未複製另一套編輯流程。

## 行為

- 金額集中為「價格與分帳」：售價 → 體驗價 → 店家固定費用 → 體驗店家費用；桌機／平板以可用容器寬度分兩欄，手機單欄，維持觸控尺寸。
- 一般費用留白＝不計算分潤、0＝店家不分配。體驗費用留白＝沿用一般費用、0＝明確不分配、另填金額＝獨立體驗費用。一般費用未設定時仍可單獨設定體驗費用。
- 一般／體驗分帳依售價即時試算，明示實際收款以折扣後實收計算。體驗時長留在原表單；多次方案沒有體驗價格／費用欄位。
- 認證、功能資格、版本比較與冪等仍由既有伺服器 writer 負責；trialStoreCost 放入既有 CHARGE_SETTING 不可變稽核，不新增 DB 欄位、不做 migration 或舊資料回填。
- 當次服務以 `person.isTrial ?? party.isTrial` 選費用，預約成立就保存有效費用到既有 SERVICE_FINANCE_RULE。收款及退款沿用原預約快照，不依日後成本重算。舊設定未含 trialStoreCost 時沿用一般費用；舊預約快照不變。
- explicit 體驗費用須為非負整數、不可超過體驗價格；未設定體驗價格時提示先補價格。繼承一般費用高於體驗價或折扣後實收較低時，沿用既有實收上限／差額提示，不產生負分帳。
- 基準 main `def55dd8`，另合併 `7f10d47d` 的公開體驗選單與按摩小提醒，保留 #1416 最新運動成本與編輯分區調整、既有 LINE／公開體驗流程。沒有變更通知或環境旗標。
