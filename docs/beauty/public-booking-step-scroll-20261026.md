# 公開預約切換步驟回頂端

顧客在手機第一步捲到底部後進入確認步驟，原本只呼叫標題 focus，瀏覽器可能保留原捲動位置，略過頁首與預約摘要。

現在切換服務／確認／成功步驟時，以 preventScroll 聚焦標題，立即回到頁面頂端，並於下一畫面更新再次固定頂端，避免行動瀏覽器的版面與焦點調整留下舊位置。取消尚未執行的 frame；同一步驟的欄位驗證仍聚焦錯誤欄位，輸入時不重設捲動。沒有修改預約資料或時段。

Chromium 隔離預覽從第一步已捲動超過100px的位置進入確認步驟，驗證 scrollY<=1；返回服務步驟及範例成功頁同樣驗證頂端，並保留已填資料與時段。尺寸360×800、390×844、768×1024、1024×768、1366×900通過，欄位錯誤仍正確聚焦。已有公開表單／預覽邊界24項測試與修改檔ESLint通過，型別與建置結果另記於PR。

證據：`evidence/20261026-step-scroll/`。全部使用範例資料及模擬後端，不建立正式預約或發送通知；本環境無WebKit，未宣稱實體iPhone／LINE容器驗收。尚未發布正式站。
