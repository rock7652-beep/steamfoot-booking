# 舒生活按摩小提醒

舒生活公開體驗表單的確認步驟，在隱私說明之後、確認預約操作之前，直接顯示淡綠底圓角提醒區。標題 16px、內文 14px、行距 1.75，三句文字不收合、不增加勾選或健康資料欄位：

- 有需留意的身體狀況，請先與店家確認。
- 需避開的部位、皮膚不適或用品過敏，請事先告知。
- 力道可隨時調整，不舒服時請直接告訴我們。

路由僅為 `soulife` 設定 `publicInfo.massageReminder`；其他美業店家不套用按摩文案。預覽以範例資料展示此內容。沒有新增查詢、儲存、資格、交易或通知行為。

既有公開表單及預覽路由 24 項測試通過，修改檔 ESLint 與 diff 檢查通過。Chromium 隔離預覽完成 360×800、390×844、768×1024、1024×768、1366×900；無整頁橫向溢出、輸入 16px、主按鈕至少44px、返回及旋轉保留資料與時間，縮短視窗後仍可捲至送出按鈕。實際使用範例資料，未建立正式預約或通知，未宣稱實體 iOS／正式 LIFF 驗收。
