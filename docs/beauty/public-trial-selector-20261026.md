# 公開體驗服務選單

公開體驗預約一律顯示「服務項目」選單，不再因只有一個體驗項目而改成固定文字。沿用店家啟用服務的即時目錄，選項包含所有已設定體驗價的服務，顯示服務名稱、體驗分鐘及體驗價；0 元體驗保留，未設定體驗價的服務不冒充免費體驗。

資料來源已核對：後台收費方式的體驗價／時長存於 BeautyService.trialPrice／trialDuration，公開目錄由同一 storeId 的 active 服務讀取。未新增價格或改動店家設定。

選擇其他服務會清除舊時段、重查資格及安排，使用所選服務的版本、體驗時長與價格顯示摘要並送出。此為公開表單的呈現修正，會員／後台、交易與體驗資格規則沿用原流程。

驗證：公開 UI／availability／資格測試 19 項通過；新增案例覆蓋多項體驗、0 元體驗、未開放排除、切換服務重查、摘要及送出內容。Chromium 隔離預覽通過 360、390、768、1024、1366 寬度及多人／重試情境，無整頁橫向溢出。證據位於 `evidence/20261026-trial-selector/`；使用範例資料，未建立正式預約或發送通知，未宣稱實體 iOS／正式 LINE 送達驗收。最終型別與建置結果記錄於 PR。
