# 美業收款、分潤與退款一致性 — 2026-10-26

## 核對結果與修正

1. 單次／體驗交易的分析報表漏讀 SERVICE_SALE_ATTRIBUTION，導致已有收款時所屬店長的交易被列未歸屬。改為與營運共用原收款快照，明確更正紀錄優先；顧客之後換店長不移動舊帳。人員刪除時保留原 ID 與待核對標示，不改算給收款人。
2. 分次收款經過退款後再補收，原程式以目前淨收款推算店家已分配費用，可能少分店家。改依每筆已保存分配、實際退款累計反轉，僅收取尚未分配的固定費用，不重複扣費。成本缺漏的舊交易仍列待核對，不用今天的價格回填。
3. 分析報表補齊店家、所屬店長、未歸屬與成本待核對金額（saleAllocation）。退款依實際入帳日期，以同一原收款的累計退款差額分攤；讀取報表區間以前的退款，避免跨月四捨五入尾差。各項合計等於區間淨收款；既有音樂／運動未帶此欄位時回應不變。
4. 營運清單、既有交易詳情與退款後預覽共用同一計算。沒有所屬店長的餘額列「未歸屬」，已作廢／尚未收款／紀錄異常分別提示。

固定費用不超過實收，未收足以 shortfall 標記，不產生負分潤。例：先收 500／店家分 300，再收 500／店家分 0；退回首筆 500 後再補收 500，店家恢復 300、該補收店長分 200，總額回到店家 300／店長 700。

這是帳面分配，不代表已實際撥款。技師拆帳及其付款仍由原本獨立月結處理，未重複計入兩方銷售分配。
