## 業務差異與保護

- 美業預約以逐位服務分項、技師及位置為資源，不搬用固定課、候補、租借與團體容量。
- 單次與體驗價格仍沿用既有服務價格資料；本批統一管理入口，沒有創造另一套價格帳本。
- 指定位置只供後台預約；不是本店啟用位置、已占用位置、多人同位置或服務加整理時間重疊，配置皆失敗。會員與公開入口不能藉此指定位置。
- 不刪除共用能力、成員授權、歷史預約、原方案或餘額；篩選成員只隱藏畫面，不移除被選的表單值。
- 儲存後等最新清單回來才開放重新編輯，避免立即重開時看到舊次數、價格或修訂版本；更新期間不覆蓋編輯草稿。
- 收費方式及家人共用操作指南已同步；未新增前台教學。

## 驗證與限制

- 39 個美業／共用讀取測試檔、307 項測試通過；涵蓋指定位置、完整時長、午夜範圍、自訂技師時間、價格互相保留、非預設方案次數、共用成員搜尋後的授權保留。
- 28 個相關指南測試檔共 175 項；其中兩檔的 Node 子程序受沙箱 EPERM 阻擋後，在允許執行隔離 mock 子程序的環境重跑 44 項通過。
- TypeScript、變更檔 ESLint、diff check 通過。正式模式建置、hosted 操作及資料核對另記於證據檔。
- 桌機／平板／手機以 Chromium 尺寸檢查，不等於實體 iPhone Safari／iPad 驗收或店家簽收。LINE 登入及通知送達仍未測，LINE 維持關閉。
- 首次或沒有可用畫面的查詢仍需網路等待；顯示先前畫面不代表新的名額或交易已獲准。沒有把測試環境測得秒數當成店家手機的保證。
