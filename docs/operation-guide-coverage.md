## 正式發布前仍需完成

1. 按現有導覽與實際可操作功能比對完整覆蓋，不以篇數作為完成標準。原 120 題是候選清單，不能視為全部已完成。
2. 補核對方案建立／上下架、詳細堂數分配與異動、匯出、員工排班、SPA 結帳等尚未覆蓋的情境；核對報表精確口徑。不存在或未開放的功能只說明限制。
3. 課程模組在獨立開發版本；待其確定版本另核對，不把隔離預覽當成 main 已上線功能。
4. 逐篇核对操作位置、成功結果、限制、角色與功能門檻；對需要圖片才能理解的步驟補真實去識別截圖。
5. 手機／桌機首次開啟、關閉、重開、搜尋、切頁、明細視窗疊加與未送出內容保留等完整驗收。
6. 完成覆蓋與驗收後再交付正式發布審核。本 PR 保持草稿、未合併。

## 手機截圖回饋優化

- 列表固定搜尋與範圍切換；分類問題列表固定返回全部分類及分類名稱。
- 閱讀文章時收起搜尋、保留返回問題列表，關閉仍固定在面板標題。
- 分類與問題卡片縮小留白；只有跨分類搜尋結果保留分類小字。
- 設定總覽跨分類推薦營業時間、提醒、付款與體驗設定；沿用權限與開通篩選。
- 1024～1439px 桌機使用 360px 覆蓋面板，1440px 起保留並排 380px；避免較窄設定頁被再次壓縮。
- 本輪 4 檔 14 項測試、ESLint、TypeScript 通過。手機與桌機最新視覺仍待實測；使用者前版截圖不作為本輪通過證據。
