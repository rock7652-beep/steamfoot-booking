## 驗收狀態

- 使用者已對 74950103 版本的手機實際滑動與桌機視覺回覆 pass／確認。此項已通過，不再列成待確認。
- 本輪 4 檔 17 項針對性測試通過：文章返回／背景內容保留、固定控制區、原因先回答、無空白提醒／結果區塊、搜尋、權限、來源路徑、捲動事件與 production gate。

## 正式發布前待完成

1. 在測試後台走完高風險情境：部分到店／未到、紙本轉入、堂數補登、退款、撤銷閉店與 SPA 多人結帳。使用隔離測試資料。
2. 補必要實際截圖：堂數管理與退款試算、SPA 日期班表與結帳。文章先回答與可選提示區塊的新閱讀效果仍需登入後檢視；這不撤銷已通過的面板版面驗收。
3. 補盤點未納入的詳細堂數異動、多店可見範圍、SPA 方案／儲值異動、通知失敗個別原因及人員權限情境。不能以 83 篇宣告全系統完成。
4. 課程模組仍須針對確定版本另行核對；不將獨立開發預覽混入此版教學。
5. 對照發布時 main 的實際規則，完成內容驗收後再決定正式發布。PR 目前維持草稿、未合併。
