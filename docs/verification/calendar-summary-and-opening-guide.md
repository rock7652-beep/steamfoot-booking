# 課表資訊小卡與初始開店引導

音樂／運動日、週課表與月曆個別課程使用共用 ScheduleSummaryButton，白色小卡沿用美業的 ServiceCardSummary 定位。顯示已載入且原本可見的課程、學員、時間、教室、老師／教練及既有狀態；不新增查詢或權限。滑入與鍵盤 focus 顯示，離開、Escape、捲動、點擊關閉；觸控保留原本明細操作，不加入第二次點擊。

美業開店設定引導只用於初始設定：已有店名、地址、電話、儲存營業時間、啟用位置、已設定價格的啟用服務及可執行服務的技師後隱藏。零元服務有效。無讀取資格或未載入資料不當成完成。Google Maps、LINE、銀行、加購方案、額外帳號、自助預約及未來七日空檔不是門檻。沒有新增完成按鈕、固定檢查入口或資料庫欄位；一般設定仍可修改。同頁店家資料成功儲存後以店家範圍事件同步，失敗不隱藏，其他店事件不影響。

- 開店引導相關 5 檔 54 項、課表相關 5 檔 34 項測試通過。

- 開店引導初始完成隱藏、最後欄位成功儲存隱藏、不同店事件隔離及一般設定保留通過。
