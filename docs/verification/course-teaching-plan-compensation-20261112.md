## 已確認規則與實作

- 教學項目 ABC 提供預設計酬。人員管理直接勾選 ABC，支援全選；未販售但啟用的項目也可選，清單計數按教學項目而非收費版本。
- 新增或修改收費方案選所屬項目，不再勾授課人員。後端仍查核本店啟用人員、項目資格及原排課資源規則。
- 每位人員可按方案獨立設定「比例拆帳（%）」或「固定費用（元／次）」；計酬資料以方案 ID 識別，不共用同價／同堂數版本。
- 新設定未覆寫則沿用項目預設；舊方案顯示沿用舊約定，既有教師個別、科目及共用設定不自動改寫。
- 方案移動大類後個別計酬保留，未另設依實際授課項目預設；跨項目運動方案亦如此。移動商品不授予人員資格。
- 固定費用每場計一次；同場相同固定金額不重複。固定金額不同或混用比例時回報待核對，不猜金額。取消、點名、請假及歷史計薪版本維持原規則。
- 課次保存方案計酬快照；既有課次不從新設定重算。已售卡的授課名單從商品政策分離。
