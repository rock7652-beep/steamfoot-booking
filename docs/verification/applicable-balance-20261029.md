# 運動／舞蹈、音樂、美業：適用方案合計

開發分支：`feat/roster-applicable-balance`。未合併 main、未部署正式站、未修改正式業務資料。

## 行為與口徑

- 名單只以「剩餘 N 堂／點／次」呈現本店、同教學／服務項目且有效適用的方案。逐張計算 `max(0, remaining - all reserved holds)` 再相加；本堂若已保留也包括在內。
- 舊方案剩 1 堂、續購方案剩 20 堂：無保留為 21 堂；本堂已保留 1 堂則為 20 堂。點名將本堂保留轉為實際扣抵，不能再扣一次合計。
- 堂、點、次分列。共用卡以卡 ID 去重，明示為共用額度，扣除全卡所有成員的保留量，不宣稱為個人獨占。
- 共用 `src/lib/applicable-balance.ts` 與 `src/components/admin/applicable-balance.tsx`。預約詳情的明細分列原方案餘額、預約保留、可用量及期限，標記本次使用來源。
- 運動／舞蹈沿用原教學項目權益判斷；音樂保留期別、期課限制、起課日期、首次上課起算效期及已核對的期初／無期限政策。補課券獨立，不加入普通方案。
- 美業保留門市、顧客可見範圍及 wallet/customer 權限；收費規則啟用時，依購入快照核對本次技師，損壞／缺漏快照不推定通用。
- 合計只供讀取顯示，不合併課卡、不重新指定既有預約的課卡，也不改交易或扣抵順序。原有交易仍重新授權、核對效期及可用額度。
- 移除以單卡低餘額直接提示續購的名單呈現；點名樂觀更新期間，合計顯示更新中，等待權威讀取。
- 美業背景同步版本涵蓋其他適用課卡、所有保留預約、服務與技師限制快照，續購及共卡他人預約會更新合計。
