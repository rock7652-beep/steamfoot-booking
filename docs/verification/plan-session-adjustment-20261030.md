# 音樂／運動／美業：調整堂數

## 範圍與版本

依本對話最新確認，三模組在持有方案原面板新增「調整堂數」。類型為「補登已上課」或「註銷堂數」，預設數量 1，原因選填；補登必填實際日期且同步扣除額度，不提供僅補紀錄不扣堂。系統保存操作人員與操作時間。另提供原紀錄「更正返還」，追加反向紀錄，不刪歷史，不重新啟用已關閉方案。整張方案註銷維持獨立入口。

來源 main：`2d9a4354b9d1f1036427581a74daacbc86b97246`。本機以既有 worktree 的相同應用來源加上該 main 的文字變更建立獨立開發快照；不將該本機合成祖先提交推送到遠端。遠端交付須以此 main 真實 tree 為父，只加入本次變更。

## 操作及資料規則

- 在原方案面板「調整堂數」選類型、填數量與補登日期，再確認；一人方案不重選學員，共卡須明確指定現有成員。送出前顯示剩餘額度變化，成功後原地更新。
- 只扣除未被預約占用的額度。堂數不足、跨店、無權查看任一相關成員、過期資料快照或已關閉方案均拒絕。歷史上課日期可早於線上建卡日（紙本歷史情境），不得晚於今天或方案到期日；已扣過的紀錄不得再次補登。
- 調整不新增排課、預約、收款、薪資、業績或補課權益。方案剩餘數量、原交易及真實使用紀錄保留；一般課卡寫入既有 `CoursePointEntry` 合法 kind，美業寫入既有 `BeautyLedger`，與不可變調整收據在同一交易提交。沒有 migration。
- 採既有模組 Store 鎖，保留後端權限、功能、門市及顧客範圍檢查。相同請求回傳原收據；相同 key 不同內容拒絕。結果未知時鎖定原內容，只重試該請求。已確認儲存但畫面同步失敗不重做交易。
- 音樂固定期別啟用時，調整占用尚未安排的期別堂次，預約、改卡與期別更正都不能重用；更正釋放原調整的堂次。較舊且缺少已核對期別的手動紀錄不猜分配，須先更正／重登。首堂效期納入有效的補登日期；點名恢復、教師未授課退堂仍保留補登首堂。手動指定的到期日維持優先。
- 期初來源匯入、特定來源方案及獨立補課卡保留原專用流程；不以此功能改寫來源基準。非固定逐期功能環境仍沿用原開通條件，不在本次自行開通。
- 管理者查看完整原因與操作人員；顧客端只投影必要上課／額度資訊，不下發內部原因與操作人員。已更正的補登不再投影為有效出席，稽核原紀錄保留。
