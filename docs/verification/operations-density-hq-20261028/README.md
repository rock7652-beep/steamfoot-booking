- 課程月結的 HQ 角色資格不再依賴新版音樂開關。頁面、人員管理的月結入口、確認、設定、付款／更正與通知人員均使用同一角色規則。保留具體門市、功能開通、訂閱、各操作權限與帳務交易檢查。

- 匯出前一行顯示門市、期間、類型、狀態及日期口徑；無門市時不猜第一家店。匯出錯誤就地顯示。
