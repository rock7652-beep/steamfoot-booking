- EXPERIENCE / TRIAL 且起訖日期均未設定：顯示「待啟用・30 天試用」，不從 Store 或 ShopConfig 的建立時間倒數。

- 已開通的試用沿用既有日期，含到期當日；次日台灣零時起停止受保護的寫入。

- 非 TRIAL 的舊版無日期體驗資料及付費店不在本次自動遷移範圍。
