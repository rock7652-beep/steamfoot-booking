# 課表月份快照補修

使用者在 PR #1524 發布後於 HQ 音樂週表跨月，仍看見整塊載入。正式網域曾漏做 promote，已另外修正；新版上線後仍存在快取問題，本補修不能用網域切換當作功能修復證據。

## 重現與修正

新增真實 CourseWorkspace 元件回歸：載入 11 月、將時鐘往後兩分鐘、讓新讀取保持未完成，再返回初始 10 月及 11 月。修正前第一次返回就出現「課表載入」；修正後保留對應月份的完整快照，同時重新驗證。

- 原 15 秒 freshness 加 60 秒 stale 顯示期限，令已讀月份在 75 秒後無法顯示。新增僅供顯示的 snapshot 存取，沿用最多五筆、帳號／店家／模組 scope 與異動失效；不延長交易資料的授權期限。
- 初始伺服器月份也 seed 到月份快取；來源 props 修訂會清除舊快照。
- 原生背景刷新只刷新本月，不清掉相鄰月份；明確修改／失效仍清除。
- 首次未讀取完成的月份仍須等待，不能拿其他月份或空資料冒充。沒有改付款、扣堂或名額檢查。

## 驗證與限制

- 六組回歸測試共 60 項通過；新增案例修正前失敗、修正後通過。
- TypeScript 通過；修改檔 lint 另隨 PR 確認。
- 三模組 Chromium 合成資料邊界案例通過：暖切月、失敗重試、快速切月、晚回應隔離與冷讀失敗。
- QA 腳本增加 --retained 可把 Date.now 往後兩分鐘，驗證快照過期後的切月；計時不代表正式效能。
- 尚未使用真實門市帳號重現 HQ 操作，未提交真實交易；瀏覽器 fixture 仍為合成資料和替代 API。
- 不含資料庫 migration 或通知設定變更。僅加入本補修分支精確 Preview allowlist，隔離條件不變。
