## 介面與資料

| 項目 | 處理與結果 |
| --- | --- |
| 指定學員／開放報名 | 指定先選人再選課，不顯示名額；開放先選課／老師再填名額，不送出隱藏學員草稿。 |
| 手機橫向溢出 | 音樂表單接上共用 Safari 日期／時間樣式，格線子欄位允許縮排；搜尋與長姓名可換行。瀏覽器驗收同時檢查整頁與視窗內局部溢出。 |
| 類型切換 | 草稿保留；切換類型回到內容頂部；底部按鈕固定。租借取消／新增樣式對齊課程。 |
| 課程來源 | 只列已連結啟用教學項目、啟用且未下架的課程；後端在儲存交易中重查；不因尚無販售方案而隱藏已啟用課程。隔離資料庫四筆虛構驗收課程未連結教學項目，現不列入音樂排課，未刪除資料。 |
| 空課程／體驗課 | 解釋需啟用教學項目與上架課程；提供另開設定入口，保留草稿。 |
| 方案顯示 | 未選課不判定待繳費；選課後逐人帶入適用方案，顯示額度與期限，可改為之後個別繳費。上課日期超過效期不自動套用。音樂名單不重複使用同一卡。 |
| 新資料入口 | 明確使用「建立新學員／建立新顧客」，和搜尋既有人員區分。 |
| 排課摘要 | 課程、教室、老師、日期／星期、起訖時間（含隔日）、頻率與學員安排方式；單次可展開全部日期。 |
| 租借摘要 | 每週同一天／同時間、全部日期、每次應收與合計；先收款標明每次與總實收。 |
| 體驗費用 | 選課後依設定同步各人費用；未選課不顯示暫時費用為確認金額。 |
| 老師與課型 | 原選老師不可授課時保留並提示，要求重新選擇。維持一位／多位學員的需求，不自行新增一對一強制限一人的政策。 |
| 浮動工具 | 原始碼未找到截圖黑色工具的來源；需於使用者實際瀏覽器確認來源與遮擋情況，未以任意全域 CSS 隱藏外部工具。 |
