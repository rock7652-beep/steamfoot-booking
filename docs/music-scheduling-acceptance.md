# 音樂排課整理與驗收（2026-10-14）

範圍：音樂後台排課、教師資格、學員方案對應、課表與預約清單。更新 PR #1317 的隔離 Preview，未合併正式站。

## 已實作規則

| 項目 | 行為 |
| --- | --- |
| 教學項目與學費 | 排課選啟用的教學項目（吉他、鋼琴等），不列價格、四堂／八堂或重複學費版本。學費、期數、有效期限仍在個人繳費與方案介面。內部排課識別不出現在學費選單。 |
| 教師資格 | 依科目對應；原有同科目的已確認授課資格可沿用。新增、修改與報名後端分別核對門市、資格與個人方案，不任意授權教師。 |
| 兩條排課路徑 | 指定學員先選一位／多位學員，再選科目與老師，不設定名額；開放報名先選科目與老師，再設定名額，建立時不必選學員。 |
| 同一排課視窗 | 固定、單次、體驗與租借在同一固定尺寸視窗切換；內容內捲動、底部按鈕固定、草稿保留。固定課選每週／隔週，不以繳費堂數限制持續規則。 |
| 教師視角空時段 | 帶入老師、日期與時間，自動查可用教室。完整時長、租借緩衝及尚未展開的固定規則都納入檢查。教室可修改，沒有空間時提示。 |
| 體驗者 | 直接輸入姓名、手機，可加入多位體驗者；省略搜尋既有學員與獨立建立按鈕。客戶資料和預約在同一交易中儲存；同手機已有可見資料則沿用，不覆寫。 |
| 體驗費用 | 讀該教學項目連結的體驗學費；未設定時讀共用體驗預設費用，不讀一般學費。多筆體驗學費不一致時要求先確認設定。後端使用權威報價。 |
| 個人方案 | 每位學員保留自己的方案、扣堂與期限；同科目的不同學費版本均可對應教學項目。沒有適用方案可先排課、之後個別繳費。 |
| 即時更新 | 新增課程、租借與調課在交易成功回傳後合併到目前課表，不重新導頁或額外整頁 refresh。跨日期調課保留原頁，提供「查看新日期」。後端儲存本身仍需時間。 |
| 卡片顏色 | 固定藍、隔週紫、單次綠、體驗橘、租借粉，填滿卡片並維持文字對比。固定課只調本次呈現單次綠；後續整批維持固定頻率顏色。 |
| 調課原格 | 淡化原資訊、只保留簡短「已調」，不寫目的教室句子；不占位、不計入堂數，可直接點空格新增。新排課即使只重疊部分時段，也隱藏整張原格影子。 |
| 覆蓋後歷史 | 新課取消不使舊影子復活；隱藏狀態永久記錄，調課歷史仍保留於詳情。 |
| 預約清單 | 沿用既有共用名單骨架、欄位與提醒，使用相同 1200／最高 900 視窗規格。音樂個人期課、繳費、日期與請假／補課資訊保留於個人詳情與展開區。 |
| 修改／取消 | 固定課保留只改本次、本次起套用，以及取消本次、取消後續。衝突逐日提示，不略過衝突日期；已完成歷史保留。 |

## 資料與相容性

- 既有學費模板、個人方案與歷史預約保留。新增課使用科目識別，並保留原有學費鐘點費例外的快照；不把所有學員合併到同一方案。
- Migration `20261014001850_music_move_shadow.sql` 僅新增影子隱藏旗標並回填已被有效排課覆蓋的影子。已套用隔離 Preview 資料庫；未操作正式資料庫。
- 排課／租借／報名沿用門市交易鎖與後端授權；前端預覽不取代儲存時的衝突、名額、額度與效期檢查。
- 共用名單保留運動模組原有業務行為；音樂個別／團體方案仍各自處理。

## 驗證與限制

- 自動化測試涵蓋科目與學費版本對應、資格、體驗報價、固定規則、租借緩衝、影子部分覆蓋與取消後不復活、個人續費，以及共用名單的提醒與展開狀態。
- PGlite 執行實際 SQL，確認影子 migration 保留原資訊、覆蓋後取消仍隱藏；鐘點費例外快照僅更新指定門市與課次。
- 實際 React 元件瀏覽器 fixture：Chromium 與 Linux WebKit，七種尺寸 1366×900、1920×1080、1024×768、768×1024、390×844、360×740、588×1000。檢查整頁／局部溢出、固定 footer、視窗尺寸、草稿、報名 payload、卡片顏色與覆蓋行為。
- Fixture 使用虛構 action，不能當作登入後完整業務驗收。Linux WebKit 也不是 iPhone／iPad 真機 Safari；真實帳號、雙帳號併發、軟鍵盤與動態工具列仍待驗。
- 完整測試結果、部署狀態與最新 Preview 連結列於 PR #1317。
