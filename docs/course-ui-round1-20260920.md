## 仍需分開處理的既有問題

- 交易歸屬目前在未指定歸屬店長時以核帳人回補（course-revenue-report.ts）；這不能當成顧客開發人指標。本輪沒有改寫歷史或統計公式，相關口徑須另外處理。
- 完整會員指南不是只補一個連結即可完成，需核對會員適用內容與權限。
- 未加入報酬、方案分潤、空間費、月結或固定期課。

## 實頁驗收阻礙

1. Chrome 原生未儲存確認視窗讓自動化命令逾時，已請使用者按「取消」。關閉該驗收分頁的嘗試被自動審核拒絕：可能丟失未儲存草稿；沒有繞過或重試關閉。
2. 內建瀏覽器仍是 HQ 会話；LIFF 外部瀏覽器提示需從 LINE 開啟，沒有冒用手機會話或更改會員關聯。
3. 桌機剩餘實頁、iPad 橫直尺寸與手機尺寸仍待補；實體 LINE／Safari／iPad 均另列未測。

## 一次整合驗收的最短清單

### 店長桌機／iPad

1. 顧客搜尋姓名並查看：基本資料可讀；切換持有方案、購買與上課、健康，仍是同一位顧客。
2. 編輯顧客，輸入暫存備註，切換分區後返回：內容保留；關閉時取消離開，內容仍保留。最後捨棄測試草稿。
3. 方案管理切換點數／堂數，搜尋持有方案：額度單位、適用課程、各卡期限清楚；展開歷史後可查閱，不改額度。
4. 營運點「查看期間待核帳」及「查看／核帳」：日期一致，同頁側窗可返回；本次不必新增真實收款。
5. 分析展開統計說明；設定進提醒管理查看独立開關，保持原設定不發訊。

### 會員手機 LINE

1. 原 A 店 LIFF → 我的方案：核對有效方案、剩餘／保留／可用與到期日；歷史可展開。
2. 購買方案 → 查看購買進度：待核帳優先，歷史另列，返回我的方案不迷路；無須為驗收重複送出購買。
3. 既有健康追蹤入口可返回會員頁，教練兼會員切換維持原權限。

本輪是整合預覽，尚未宣稱全部實頁與裝置驗收完成；不對外開通體驗店。
