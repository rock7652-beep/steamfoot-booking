## 已修改

- 名單參照蒸足 day-detail-panel：獨立勾選欄、緊湊摘要、操作藏於展開詳情；保留批次點名。
- 課程設定移除薪酬欄位；人員按授課資格只設定每堂固定費，預設 0。伺服器拒絕新的時薪/拆帳設定。歷史快照不重算。
- 新排課只取該老師每堂固定設定；未設定 0。隔離 PostgreSQL 以 90 分鐘課次驗證產生 CLASS/0 快照，測試交易已回滾。
- A 店指定 OWNER 帳號原 transaction.discount=false，已依使用者要求修正 true，AuditLog 記錄 Codex 執行及使用者授權原因。其他帳號權限未調整。
- 方案加入店家成本（預設 0）；指派指定本次開發人；折後實收減成本為開發所得，保存金額/人名快照。不得自行以核帳人代替開發人。
- 發卡、實收 CashbookEntry、開發人歸屬及購買紀錄同交易完成。舊交易不回填臆測分配。營運顯示分配，退款依累計退款比例顯示沖回，原購買與退款紀錄保留。
- 期課連結指定課次，堂數必須吻合；結帳整期預約、任一堂失敗整筆回滾。期課卡不可共卡或改用別堂；未到扣堂、更正返還不重複扣抵。已有購買的期課不可改寫期別課次；舊卡不變。
- 名單顯示期課第 N / 共 N 堂；自由預約卡不偽造期別。
