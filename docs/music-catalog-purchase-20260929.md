# 音樂教室管理與購買調整（2026-09-29）

## 定案
- 方案管理儲存單期收費：名称、每期堂數、每堂學費、每期有效天數。教學項目、課型和上下架保留；排課方式與購買／共用選項收在進階設定。
- 購買期數、折扣和贈課移到學員繳費，課表快捷繳費與顧客頁共用同一組件與伺服器計算。
- 買三期四堂送一堂：一筆購買、13 堂，期別快照 [5,4,4]，35 天乘三＝105 天。
- 買六期四堂：24 堂，35 天乘六＝210 天；每期30天則180天。
- 整份購買從首次有效扣堂課程日期起算；付款、單純預約不啟動。贈課不自動延長，購買時可另設總有效天數。
- 新購買快照的 musicTermSizes 包含第一期贈課；musicBonusLessons 是贈課總數資訊，不再新增一期。舊購買依總堂數判別原始獨立贈課段，歷史不重排。
- 舊多期商品不直接批次轉換或刪除，編輯儲存後改成單期收費；已購快照保留。
- 四個管理清單支援把手拖曳、鍵盤上下移動及復原，保存門市共用順序；有篩選時不能拖曳，上架與下架各自排序。
- 課程順序同步課程選單，方案順序同步購買選單，教室與老師同步課表輸入順序。
