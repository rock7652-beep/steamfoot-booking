# 課程前台統一手機版與串接補齊

本輪以 32c81db 為基礎，只更新隔離預覽分支。

## 修改
- 顧客／教練前台、底部功能列、彈出面板最大寬度 430px，桌機置中；移除桌機側欄、雙欄課表及收合控制。
- 成功完成 LIFF 身分交換後，課程模組直接進入同一個 /book 前台；在蒸足摘要與 SPA 工作分流之前處理，未改動原登入驗證。
- 健康追蹤沿用既有曲線與紀錄元件，顯示九項量測指標。查詢限定本人及本店，仍需開通健康功能；最近100筆及總筆數明確標示，沒有新增顧客自行編輯功能。
- 每60秒及返回前景時刷新，15秒節流；背景、編輯面板或操作進行中跳過。另提供手動更新與資料時間。
- 授課紀錄同日合併、加入出席篩選；出席、未到、待點名標籤區分。
- 面板依 visualViewport 調整可用高度，保留原頁捲動與輸入。

## 驗證
- TypeScript、受影響檔案 ESLint 通過。
- 6份既有測試共36項通過：健康存取、方案交易、出席更正、LIFF session refresh、SPA分流及中央會員路由。
- 驗收瀏覽器讀取測試頁時回報 CDP refresh tabs 20000ms timeout；未能完成新版登入後的實際操作驗收。
- 待實測：375/390/430px與桌機一致、手機鍵盤/滾動、LINE內登入至課程前台、前後台變更刷新。
- 上述自動測試不替代完整交易驗收，也不代表實體 LIFF 已驗收。
