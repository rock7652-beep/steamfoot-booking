# 課程月結整合

## 行為
- 沿用月結管理授權；課程店導向按人的利潤／授課費清單，其他模組保持原計算器。
- 店家兩個設定預設開啟，沿用既有運作。关闭利潤只影響新購買（既有待核帳訂單保留原分配）；关闭授課費只影響新排課。舊課次、付款、費率設定均保留。
- 利潤依方案核帳月份、授課費依上課月份歸屬。只納入已結束課次。
- 退款沿用累計比例沖回；退款／作廢重算原月份，當月有舊單退款時顯示原月份連結。
- 確認建立不可覆寫版本；確認與付款分離。金額變更後需確認修正版才能從月結付款。
- 利潤支持分次登錄、請求重送去重、店鎖防併發、支出與稽核同交易提交。已付授課費直接讀既有帳本，不再生成另一套付款。
- 溢付保留並標示待核對；誤登更正只沖回帳務，不等於實際收回款項。沒有自動轉帳。
- 旧資料缺失不當零元，阻擋確認；未設定費率的新課次仍沿用既有 0 元規則。
