# 音樂教室購課與分次收款（測試站）

## 範圍與資料

- 僅 `feat/music-opening-state-20261007`、`store-lubymusic`、隔離 Supabase `ttworfzgwejdeolegkxl`；未部署正式站。
- 新購課以 `CourseMusicTuition` 固定應收與折扣計薪選項；`CourseMusicReceipt` 保存每次實收及付款日。既有匯入／歷史購課不推算或回填付款。
- `CoursePurchase.price` 維持累計實收（退款上限），不是應收。收入報表、首頁與營運分析以收款事件日期計算；補繳不產生課卡或 GRANT。
- 方案 × 購買期數沿用現有購課設定；各期應收均分，最後一期吸收整元餘數；實收按期別順序抵付。各期共用此次購課期限。可調整共用有效天數，起算方式仍為首次扣堂。
- 勾選折後學費拆帳時，以固定應收／原收費堂數計算單堂基數，最後一步才取整元；未勾選沿用原單堂價。補課沿用原課卡的選項。
- 分次繳費購課使用退款保留原收款，不允許直接作廢有實收的訂單。退款／作廢後禁止補繳。

## 入口

- 學員 → 購買方案；課表 → 學員 → 購買方案。
- 學員 → 購買／付款紀錄 → 各期／繳費紀錄 → 新增付款。
- 各期列有堂數、應收、已收、未收、點名。點名資料需 booking.read；新增付款需 transaction.create。

## 防重複與會計

- 購課與補繳在既有店家交易鎖內執行；兩者均有冪等鍵。
- 重送購課即使已補繳仍返回原購課；每次補繳檢查即時累計實收與剩餘應收。
- 付款日期為台灣日期，不能填未來或不存在日期；現金付款須該日現金抽屜開啟。
- 退款逐筆核對收款事件與現金簿，避免以尚未收到的款項退款。
- 新表啟用 RLS 並撤銷 anon/authenticated 權限，經具店家權限的後端交易存取。
