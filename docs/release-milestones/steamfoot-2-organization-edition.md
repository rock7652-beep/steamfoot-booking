# SteamFoot 2.0 - Organization Edition

## Milestone

Store Organization v1.

Status:

GA.

Production Release Review:

PASS.

Release date:

2026-07-01.

## Summary

SteamFoot 2.0 - Organization Edition marks the point where SteamFoot evolves
from a single-store operating system into a brand platform while preserving
store independence.

The release introduces:

- HQ Store Organization.
- View Mode.
- Dashboard Full Read, Zero Write.
- Customers Full Read, Zero Write.
- Bookings Full Read, Zero Write.
- Plans Full Read, Zero Write.
- Cash Drawer Full Read, Zero Write.
- Reports Full Read, Zero Write.
- Return to own store.
- Safe refresh, logout, and login behavior.

## Release Principle

Store Organization represents a view relationship, not a management
relationship.

View Mode provides full read access and no data mutation capability.

## Production Release Review Result

PASS.

Validated on production:

- HQ organization page.
- Store manager normal mode.
- Store manager View Mode.
- Full Read behavior.
- Zero Write behavior.
- Return to own store.
- Refresh after return.
- Logout/Login returning to own store.
- No browser console errors observed during release smoke.

## What This Release Does Not Do

- It does not create multi-store management.
- It does not grant upper stores operational control.
- It does not attribute revenue across stores.
- It does not create rankings.
- It does not change settlement or commission rules.
- It does not introduce HQ analytics.

## Closing Statement

This release establishes a product architecture where SteamFoot can support
brand growth without turning store organization into interference.

The purpose is trust, companionship, and shared experience.
