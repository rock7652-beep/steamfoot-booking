# 課程設定右側視窗

## 範圍

八個設定入口改為同一設定工作區的右側視窗：營業／公休／預約開放、值班聯動、體驗、未指派方案、提醒管理、顧客關懷、推薦分享、數位管家。

- 重用各頁伺服器資料讀取、權限與儲存動作；沒有 iframe、沒有新增 API 或資料表。
- 寬內容按需讀取。桌機靠右，手機滿寬；固定標題與關閉鈕，內容獨立捲動。
- 關閉回到原設定分類；未儲存的店家／銀行草稿仍保留。
- 視窗內提醒分頁、發送紀錄篩選／翻頁、關懷月份及未指派名單翻頁保留在視窗。
- 子表單回報真實 dirty/pending 狀態；關閉、遮罩、Escape 與視窗內導覽需先處理草稿，儲存中不能捨棄。
- reload／關閉分頁採瀏覽器 beforeunload 警告；瀏覽器上一頁不是應用程式的關閉按鈕，未新增通用路由攔截器。
- 顧客詳細／課表等跨工作流程仍導向既有工作頁；LINE 綁定等外部流程保留。
- 直接開啟原各頁網址仍可正常使用；蒸足與 SPA 的獨立設定頁不套用視窗。

## 驗證

- TypeScript 通過。
- ESLint（修改檔案與新增元件）、git diff --check 通過。
- 7 組 43 項回歸測試通過：全部入口、門市前綴、設定分類、背景 query 保留、視窗內篩選、草稿／儲存保護、巢狀 Escape、既有設定與營業時段／值班回歸。
- 部署後另驗收原 A 店八個入口、關閉返回、頁籤／月份、未儲存保護與可逆儲存。
