# 課程授課費接續：付款與誤登更正

接續 PR #1052 的 6b08537e；使用者在新對話要求接續截圖四項工作，既有驗收後發布授權持續有效。

## 本輪實作

- 營運課次列表顯示每堂固定費、零元不另領、待付、已付。保留原課次快照，不因學員人數多扣。
- 店長確認已付後，付款、現金帳支出及稽核同交易寫入；課程店鎖與唯一索引避免同時送出重複付款。現金沿用抽屜開啟檢查。
- 誤登更正保留原付款、原因、操作者，反向沖回原支出；更正重送不重複沖回，可另開新付款請求。不是實際匯款或收回款項。
- 付款及更正均檢查店長、cashbook.create、課程店別與訂閱可寫。一般現金帳不可單獨編輯／刪除連動支出或沖回。
- 未設定／舊時薪或拆帳快照不臆測成零元；小數費率待核對（現金帳目前整數元）。取消、未結束、身分或費率不一致不能付款。
- 列表依課次日期，最多顯示100堂並提示縮短範圍，沒有將截斷結果當完整總計。
