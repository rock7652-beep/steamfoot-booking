# 課程介面第二輪：計酬設定、批次操作與備註

基準 PR #1052 / 5deb0efe；沿用原 A 店隔離預覽，未合併或正式部署。

## 修改
- 課程體驗資訊移至操作指南旁的可展開提示，保留用量、期限與保留期資訊；其他模組不改。
- 方案表單採桌機雙欄、適用課程限高與搜尋，搜尋不取消原勾選。
- 教室、人員、方案加入逐筆勾選、全選篩選结果、批次啟停用或上下架。失敗整批回滾；人員額度、自我停用及教室在用檢查保留。顧客持有卡、期限、額度不批次修改。
- 課程查看側窗新增計酬設定，可複選每堂／時長／拆帳及預設值；人員查看→授課與工作→課程計酬設定單選並可改值，只有一種時帶入。新建人員先儲存授課資格再設定。既有未設定費率不猜測補值。
- 計酬設定保存後僅供新排課使用；資料庫觸發器覆蓋新增、複製與重複排課。換老師／課程重新取設定；原課次的費率不因預設值更新而改变。既有課次不回填。
- 每堂固定一次；按排定分鐘計時；拆帳公式以實收乘本次額度占原始總額度比例，再乘教練比例。提供公式驗證，不包含薪資月結、付款、未到報酬或退款後報酬結算。
- 店內備註供店長與該堂授課教練查看，本次備註限定該預約；會員輸出不傳回內部本次備註。舊顧客備註原文保留、收合管理，與服務備註一起展示於店內備註，沒有刪除或覆寫既有內容。

- TypeScript 通過；新增模組 ESLint 通過。
- 7 組、52 項針對性測試通過：公式、多選／單選、自動帶入、跨店、未開放方式、資格、版本衝突、批次自我停用／額度／教室阻擋與既有教練操作。
