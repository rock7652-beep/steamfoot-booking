# 顧客關懷流程

本次將既有關懷條件與處理紀錄連接，不取代原本的購買、回店或預約判斷。

| 情境 | 呈現與後續 |
| --- | --- |
| 當年度生日已祝福 | 移至「已處理／已安排」；不同年度與其他關懷原因不受影響 |
| 體驗未轉換方案 | 沿用各模組的轉換條件；關懷可設定下次追蹤日期 |
| 久未回店但已有未來預約 | 顯示「已預約」；取消後重新依追蹤日期判斷 |
| 實際完成回店 | 原有回店條件重新計算，不再符合時移除提醒 |
| 已設定下次追蹤 | 日期之前列為已安排，到期後回到待關懷 |
| 額度不足／快到期 | 各自追蹤；不因其他原因的關懷而一起消失 |

關懷紀錄按原因分開保存。舊紀錄維持一般聯繫，不推定為生日祝福或新流程的處理完成。「已預約」以各模組的實際預約為準，手動選擇聯繫結果不會建立預約。沒有關懷紀錄的條件解除不會額外產生歷史事件。重新讀取頁面時更新其他流程造成的變動，並未新增即時推播。

同頁預約沿用蒸足、SPA、課程現有新增預約與容量／方案驗證。紀錄祝福不會發送 LINE。課程保留剩餘、已預約與可用額度。
