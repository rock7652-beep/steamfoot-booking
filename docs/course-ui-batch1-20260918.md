本批為共用視覺、側窗、左側導航、首頁；保留既有交易及身分規則。首頁今日工作優先取代舊版現金抽屜置頂要求。報酬、方案分潤、空間費與月結計算未實作。未執行資料遷移、正式資料寫入、合併或正式部署。

## 修改

- 課程導航分為「日常工作／店務設定」。顧客經營、數位管家沿用原有入口、角色及方案門檻；未新增功能授權。分組判斷包含課程 view，首次展開兩組。
- 首頁先顯示今日課程、真實人數／人次／未完成摘要及快捷操作，現金與收支在後。未啟用現金功能不阻擋課程首頁。
- 「新增排課」直接開排課表單；「替學員預約」開當日課程。具有交易查看權限且確有待核帳資料才顯示提示。
- 今日課程列可原頁開名單。課程／教室／排課及今日名單採共用側窗緊湊模式，沿用品牌色，縮減表單留白，內容獨立捲動。
- 課程編輯有未儲存確認，取消離開保留輸入；鍵盤焦點限制在側窗並於關閉返回原控制項。
- 共用 RightSheet 預設模式保留；緊湊模式採明確 opt-in，不將新樣式自動套到蒸足／SPA。
