# 課程方案依科目計算與扣抵規格

日期：2026-11-10（Asia/Taipei）。狀態：**使用者已確認業務規則，待程式實作；不是已發布功能**。

## 決策與範圍

使用者確認：「A 類如果開放選課或指定學員，在 A1、A2、A3 的方案都會計算；若顧客有 B1、C2 方案，科目不同就不予計算。」並確認名單可合計同科目額度，實際扣堂只扣其中一份，留下來源。

A 是教學科目；A1、A2、A3 是該科目的不同收費方案／購買份數，並非三次扣堂。開放選課與指定學員是加入課程的方式，不是科目資格。固定每週／隔週／單次是排程頻率，也不作為排除同科目方案的條件。

本規格先處理課程模組（舞蹈／運動原生權益）的選課模式耦合；不借機改寫音樂來源卡、補課權益、美業、退款或計酬規則。共同元件可共用，其他模組維持各自資格。

## 已確認的資格規則

1. 以後端核對的**同店科目識別碼**比對課程與購入課卡；不同方案 ID、名稱、售價或堂數不代表不同科目。不得依「名稱含 A／芭蕾」、課表顯示分類或前端聲稱的科目判斷。
2. A 課程對 A1、A2、A3 使用相同科目資格判斷；開放選課、指定學員及同堂混合名單的學員都適用。B1、C2 不列入 A 課程的額度，也不得自動扣抵。
3. 科目符合之後，仍核對會員／共卡成員可見性、店別、有效期、已停用、已保留額度、老師限制、班級資格、名額、指定日期／期課與原課程補課限制。分開科目與選課方式不等於放寬其他限制。
4. 課程自行選課開關、店員排課權限、可預約時間窗照舊；持有 A 方案不等於可以自行加入尚未開放的 A 課程。

## 合計顯示與實際扣抵

- 名單以符合本堂資格的課卡合計。每張卡只計一次，共卡不因成員或預約列重複累加。
- 「剩餘」與「可用」分開：可用額度扣除有效預約保留，不把未來已預約的額度重複提供。效期以本堂上課日期與既有到期規則核對。
- 堂數與點數分組顯示，不將點數直接加成堂數。格子仍依單份方案的授予總堂數及有效上課紀錄呈現，不把不同卡的歷史合併成一張卡。
- 已有有效綁卡的預約沿用其來源，保留既有額度與費用快照；不因這次新規則重新分配已預約或已扣抵的卡。
- 尚未綁卡且需要自動選卡時，沿用現有 `purchaseOrder` 的先買先用及穩定排序，在符合資格且額度足夠的卡中挑一份；不新增到期日優先等另一套排序。
- 一次出席只從選定的一張卡扣所需額度。A1、A2、A3 都符合不代表三張都扣。堂數方案沿用一次一堂，點數依原已保存規則；缺課、請假、更正與還點維持原交易流程。
- 保留交易鎖、重送防重複、預約來源 cardId、實扣數量與稽核紀錄。撤銷或更正應回到原扣抵卡，不能補到另一份同科目卡。
- 無合格卡時顯示可理解的原因，例如「科目不符」「方案已到期」「可用額度不足」「方案科目待核對」；不將所有情況一律寫成「沒有方案」。

範例：A1 可用 3 堂、A2 可用 5 堂、A3 可用 2 堂，B1 可用 8 堂、C2 可用 6 堂。若其他資格皆符合，A 課程顯示可用 **10 堂**；出席一次只扣某一張 A 卡的 1 堂，合計剩 9 堂，B1／C2 不變。兩種加入方式結果一致。

## 設定介面與權益快照

- 收費設定清楚顯示「適用科目」，A1、A2、A3 可選同一科目；選擇開放選課不得清空科目。排課／自行選課開關保留在原本課程安排設定，不用方案名稱暗示模式。
- 購買時將已核對的科目、單位、扣抵數量及其他必要限制保存到訂單與課卡。核帳沿用訂單快照，不在核帳時重新套用已改過的商品設定。
- 編輯商品只影響後續購買。已購卡餘額、效期、購買時間、上課紀錄及已保留／已扣堂資料不因編輯商品而改寫。
- 原介面曾提供「通用卡」；這次 A 類規則不授權把無科目的舊卡全部改為 A，也不授權將所有 A／B／C 方案混算。是否另保留明確跨科目商品，屬另外的商品規則，不以空值代表已核准跨科目。

## 既有卡與林仲萱個案

- 已有可靠科目對應的卡，盤點它的持有人、店、科目、既有預約與餘額，供相容處理與回歸驗證；不重發另一份額度。
- 科目缺失或互相衝突的舊卡列「待核對科目」，由有權限人員確認明確對應；不能解析方案名稱猜科目、依目前商品內容回填歷史卡，或把不明卡當成全科通用。
- 如需變更既有已購卡的適用範圍，先列原／新權益、受影響預約與具體卡片清單，取得該批資料的明確確認，再以有權限、有稽核、可查驗的流程處理。不得直接執行大量 UPDATE。
- 本聊天唯讀查核當時，林仲萱可用 19 堂的已購卡為 OPEN，沒有科目識別碼；該堂名單則是固定安排的學員，現行模式判斷因此排除這張卡。**19 堂與歷史不重算、不清零、不要求重買**；要依本規格扣 A 科目前，需核對該卡的實際科目，不能僅由「舞蹈（零基礎成芭）」名稱推定已完成對應。

## 必要驗收案例

| 案例 | 預期 |
| --- | --- |
| A 類開放選課／指定學員，各持 A1/A2/A3 | 合計相同；每次只扣一份 A 卡。 |
| 同一班有固定學員及自行選課者 | 相同 A 科目卡的資格一致，保留各自名額與預約規則。 |
| A 類學員另持 B1/C2 | A 額度不含 B/C，出席後 B/C 餘額不變。 |
| A 類已有有效綁卡／多張未綁卡 | 前者沿用來源，後者沿用先買先用；重送不重複扣。 |
| A 卡到期、停用、老師不符或額度全保留 | 排除該卡並顯示原因，不能因同科目繞過限制。 |
| 多位學員共享同一張卡 | 每人名單可依法顯示；共用預約與交易不超扣，合計去重。 |
| 同科目混合堂數與點數 | 分組合計、保留原扣抵規則，不能混加成堂數。 |
| 同名不同店／改名／商品改科目 | 不跨店、不憑名稱；已購卡快照與歷史不被商品修改覆蓋。 |
| 舊 OPEN 科目未知／舊模板可核對／補課卡 | 未知明示待核對；可靠別名同店核對；補課仍受原課程限制。 |
| 取消、撤銷點名、缺課更正及併發 | 原卡原數量還點，既有請假／缺課規則不變；沒有部分寫入或重複扣堂。 |

## 本機實作狀態

後續本機分支 `feat/course-subject-entitlement-20261110` 已實作共用科目資格、兩種選課方式的資格與名單合計、收費與選項篩選，以及店長核對舊卡科目的交易入口。沿用 `ASSIGNED` 作為既有資料庫的「已指定科目與扣抵數量」快照，不再表示僅限指定學員；沒有 migration，也沒有將舊 OPEN 卡推測為任何科目。

舊卡入口只改該卡的科目快照，不改商品、訂單、餘額、到期日與帳本；要求店家、人員權限、明確確認、版本核對與同交易稽核，已有不同科目或扣抵數量的預約會阻擋。正式顧客尚未批次回填或確認。
