# 當日新預約 LINE 提醒

- 入口：提醒管理 → LINE 主動通知人員 → 每位人員的「當日新預約提醒」。
- 預設關閉；需先綁定該店官方 LINE 並啟用通知人員。
- 僅蒸足顧客自行新增的當日預約：會員網頁／LIFF 會員與體驗預約、公開體驗表單。
- 以共用 Asia/Taipei 日期函式判斷建立日與服務日。
- 後台手動新增、預約重送回放、未來日、取消、SPA 不觸發。
- 每位人員的偏好獨立保存；沿用現有同店通知設定管理權限。
- 只使用資料庫中明確開啟的收件人，不退回環境變數收件人。
- 預約交易提交後才通知，查詢或傳送失敗不能改變預約成功結果。
- 現有新體驗／續購等通知規則保留，公開體驗可能同時收到既有體驗通知與新增的當日提醒。

## 發布前

此 PR 尚未執行正式資料庫異動或發送真實 LINE。
需先在 Preview 專用資料庫套用 `20260914100000_same_day_manager_reminder`，再驗證設定頁與儲存。
正式發布前須先依既有受控資料庫發布流程套用同一 migration；不可只部署新 Prisma client。
現有 `ci-migrate.mjs` 使用限定 migration target，本 PR 未擴大其允許範圍。

## 驗證

針對通知時間、店別、開關篩選、失敗隔離，以及設定 action 權限／跨店阻擋進行單元測試。
既有 LINE 通知、LIFF 預約 action、預約店別一致性與公開體驗通知接線亦執行回歸。
