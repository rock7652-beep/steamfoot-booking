# 蒸足系統方案與加購模組｜限時優惠價

## 一、定價定位

此方案為「限時優惠價」，約為正式原價 7 折。

適用於限時推廣期間申請之合作門市。

未來優惠期結束、功能升級或服務內容增加後，方案價格將依正式原價調整。

## 二、主方案價格

### 基礎版

- 原價：$2,100 / 月
- 限時優惠價：$1,490 / 月
- 定位：單店基本營運
- 內含：基本營運功能 + 可選 1 個 $500 工具型模組

### 專業版

- 原價：$3,600 / 月
- 限時優惠價：$2,490 / 月
- 定位：想做好顧客經營與現場管理的店
- 內含：基礎版 + 顧客經營 + 現金抽屜
- 另可選：1 個 $500 工具型模組 + 1 個 $800 經營型模組

### 展店版

- 原價：$7,100 / 月起
- 限時優惠價：$4,990 / 月起
- 定位：總部、多店、合作店長模式
- 內含：功能全含
- 包含：總部管理 + 1 家分店
- 第二家分店起，每增加 1 家，收取 $1,000 / 月分店營運費

## 三、加購模組分類

### $500 工具型模組

- LINE 自動提醒
- 資料匯出
- 現金抽屜

### $800 經營型模組

- 顧客經營
- AI 健康摘要
- 經營診斷報表
- 月結管理

工具型模組偏向現場作業、提醒、匯出、帳務管理。

經營型模組偏向回訪、健康摘要、經營判斷、結算管理。

## 五、展店版分店營運費說明

展店版 $4,990 / 月起，已包含總部管理 + 1 家分店。

從第 2 家分店開始，每增加 1 家，收取 $1,000 / 月分店營運費。

此費用包含：

- 分店資料維護
- 顧客 / 預約 / 收款 / 報表資料
- 分店帳號與權限
- 前台預約入口
- LINE 綁定與提醒設定維護
- 總部管理資料同步
- 系統維護支援

正式用語使用「分店營運費」，避免以「加店費」作為主要說法。

## 六、功能價值說明

### LINE 自動提醒

自動提醒顧客預約，降低忘記與未到。

### 資料匯出

匯出顧客、報表、營收資料，方便會計、總部與備份。

### 現金抽屜

管理每日現金、開店實點、收支異動與交班核對。

### 顧客經營

找出很久沒來、方案快到期、生日顧客，協助店長追蹤與回訪。

### AI 健康摘要

串接 HealthFlow，在顧客詳情查看健康摘要；完整量測紀錄仍回 HealthFlow 後台查看。

### 經營診斷報表

看懂體驗轉正式、續購率、回訪率、客單價與沉睡顧客，知道店裡真正漏在哪裡。

### 月結管理

合作店長每月結算、固定月費、分潤、加扣項與歷史紀錄管理。
