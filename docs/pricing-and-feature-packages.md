此方案為「限時優惠價」，約為正式原價 7 折。

## 五、展店版分店串接管理費說明

展店版 $4,990 / 月起，已包含總部管理＋首家分店串接額度（分店系統月費另計）。

從第 2 家分店開始，每增加 1 家，收取 $1,000 / 月分店串接管理費。

此費用包含：

- 分店資料維護
- 顧客 / 預約 / 收款 / 報表資料
- 分店帳號與權限
- 前台預約入口
- LINE 綁定與提醒設定維護
- 總部管理資料同步
- 系統維護支援

正式用語使用「分店串接管理費」，避免以「加店費」作為主要說法。

## 六、功能價值說明

### LINE 自動提醒

自動提醒顧客預約，降低忘記與未到。

### 資料匯出

匯出顧客、報表、營收資料，方便會計、總部與備份。

### 現金抽屜

管理每日現金、開店實點、收支異動與交班核對。

### 顧客經營

找出很久沒來、方案快到期、生日顧客，協助店長追蹤與回訪。

### 健康評估與體態追蹤

記錄量測數據、歷史紀錄與變化趨勢，協助日常追蹤與顧客關懷；不作醫療診斷或效果保證。各門市保留獨立開關，關閉不刪除歷史資料。

### 分析

看懂體驗轉正式、續購率、回訪率、客單價與沉睡顧客，知道店裡真正漏在哪裡。

### 月結管理

合作店長每月結算、固定月費、分潤、加扣項與歷史紀錄管理。

## 2026-09-12 定案：總部管理與分店訂閱分開計價

- 展店版 NT$4,990/月，含總部管理與首家分店串接額度；不贈送分店系統訂閱。
- 第二家起每家 NT$1,000/月串接管理費。無固定 3 家上限，可加購至 30 家以上。
- 每家分店另外購買基礎版 NT$1,490/月或專業版 NT$2,490/月，工具依該分店方案選配／加購。
- 3 家專業版分店：系統月費 3 × 2,490 + 總部管理費 4,990 + 2 × 1,000 = NT$14,460/月。
- 總部功能不向下繼承；組織調整不修改分店的 PricingPlan 或功能覆寫，也不移轉顧客、營收與方案所有權。
- 已購串接額度由平台 ADMIN 確認後登記，保存稽核紀錄；尚非自動金流或自動帳單。
- maxStoresOverride 保留原本「含本店」語意：總部買 31 家串接額度即記錄 32；null 使用首家串接預設。
- 每個展店版總部計算自己所有下層門市，包含間接下層。不同總部不共用額度。
- 既有超額關係不自動移除或改帳單；禁止再增加超過額度的串接，降低額度不能低於已串接數。
- LINE 官方帳號訊息費、第三方金流手續費、數位管家另案計算。
