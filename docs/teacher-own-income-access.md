# 教師／教練查看自己的薪酬

- 音樂：教師管理 → 選擇教師 → LINE 與權限 → 我的工作權限。
- 運動：教練管理 → 選擇教練 → 工作帳號 → 我的工作權限。
- 「允許查看自己的薪酬」預設關閉，只有老闆可設定；總部已授權店家視角依老闆身分操作，稽核保留實際操作者。
- 保留門市月結既有「開放人員查看本人收入」總開關及服務費功能授權。需完成 LINE 綁定、逐位授權，且月結已確認，才可查看本人已確認收入。未確認月份顯示待確認，不當成零元。
- 老師端沿用「我的工作」帳號選單中的「我的收入」，只讀取本人資料。無權限不顯示入口，直接開網址也拒絕；每次查詢與回傳前重新核對授權。
- 不提供老師修改拆帳／鐘點、確認月結、登錄付款或查看別人的功能。薪酬計算、付款與扣堂規則不變。
- 不會自動授權既有教師／教練，也不自動開啟門市總開關。沿用 StaffPermission，不新增資料庫 migration。

## 驗收

1. 老闆開啟某位教師／教練的開關；重新開啟編輯確認保存。
2. 保持其他老師關閉；老師「我的工作」只在授權且門市總開關已開時顯示我的收入。
3. 已確認月份只顯示本人，未確認月份顯示待確認；不顯示其他人的金額、付款備註或識別碼。
4. 關閉該人權限後重新讀取收入，或直接開收入網址，必須被拒絕。
5. 非老闆只看開關狀態，不能修改；另一門市的人員不能作為授權對象。
6. 桌機 1366px、1024×768／768×1024 iPad 與老師手機 360／390px 檢查入口、文字及主要操作。

瀏覽器安全限制下，單元測試或模擬 DOM 不代表真實登入／裝置已完成驗收。
