## 實際修改

- 同一教學項目使用同一課程模板，兩種選課模式共用教練資格。教學項目設定與教練管理都讀寫既有 `Staff.courseQualifiedTemplateIds`，沒有新增另一份資格資料。項目面板提供開放課扣點與既有計酬設定；尚未指派教練可先儲存項目，排課仍須有效資格。
- 收費方式區分指定項目方案與開放選課通用卡。指定方案只選項目與購入扣抵規則，不重設教練；通用卡不要求單一項目、扣抵或教練。表格及會員專區明確顯示適用開放選課。
- 排課不送出購買方案 ID，由教學項目取得課程規則及合資格教練。正式開放課不因方案 ID 為空而誤建成體驗。
- 有限排課、後台單筆加入、後續批次加入及固定課點名使用 `findSportsCard`。在原 Store 交易鎖內，核對模式、項目、授權成員、期限、指定課次、可用餘額及補課券限制，依較早到期／穩定 ID 順序自動選卡。有限批次整批足額才成功，不拆卡。
- 永久固定名單仍不預留課卡或預扣額度，點名才選卡與扣抵。自動預約重送重用原預約課卡，不因當下餘額或期限改變而重新選卡。
- 一般預約、候補及同行使用方式更正共用權益政策。指定課不接受匿名同行或自行候補；通用卡不能轉用指定課。會員可用權益及購買篩選沿用同一判斷。
- 舊卡維持原方案／模板限制。沒有方案綁定的新模式課，不默認接受舊卡，即使舊卡的模板清單為空。一般編輯省略隱藏欄位時保留原新模式權益，不默默改回 LEGACY；未讀取的舊方案計酬也不以表單預設值覆寫。
- 權限、門市與原部署 readiness 檢查保留。項目規則另驗 `staff.manage`、`teacher.compensation.manage` 及店長角色；過期教練／計酬編輯拒絕，教練有未結束課次時不能移除資格。變更保留審計。
