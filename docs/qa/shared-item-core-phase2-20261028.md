- 美業：尚未完成的普通綁卡預約同樣依服務項目選最早有效卡，保留原預約、原購買、原扣次紀錄及改卡前後稽核。啟用收費規則時仍檢查技師資格與費用快照；已付單次及體驗沿用各自流程。
- 美業等原生顧客面板儲存後使用自身讀取器與既有顧客失效事件更新，避免額外整頁 refresh；一般非來源面板保留原刷新機制。畫面串接驗收另抓到嵌入式購課面板會改寫名單網址，已停用該嵌入情境的顧客頁網址同步，獨立顧客頁仍保留原機制。
