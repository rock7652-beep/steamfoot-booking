# 課程原地購課效能驗收

> 本次上線審查版本不包含新增的驗收截圖及原始結果檔；下列 artifacts 路徑為當時紀錄的來源，並非此版本內的連結。驗收結論僅適用所載版本及條件。

**結果：繳費視窗讀取改善、業務正確性通過；整體效能尚未通過，暫不正式上線。** 最終確認購買仍有10秒慢樣本，不把前端讀取變快當成結帳全面完成。

本輪處理運動／音樂原地購課的身分重複驗證與序列權限檢查。正式站未發布；美業獨立購課、學員資料頁其他讀取、歷史補登及效期操作不在本輪宣告完成。

## 修正

- 單次結帳作用域共用經伺服器驗證的身分；沒有跨請求身分或財務資料快取。即使外層有讀取作用域，新的結帳仍重新驗證。
- 購課與收款權限可並行，但仍分別檢查授權、功能資格與有效門市成員。兩項結果須同一門市及身分；折扣權限、交易鎖、會計規則、FIFO 與流水均保留。
- 原本依精確 actor 物件共用的門市確認現在可生效；拒絕結果不轉為允許，下次請求重新檢查。
- 名單購課選項使用相同作用域，增加不含個資的後端階段計時。
- 第二階段把原生運動／音樂的購課選項改由 scoped GET 讀取，沿用同一授權服務與共用 panel reader、TTL 0，避免在 Server Action 佇列等其他介面讀取；關閉／切課的世代保護不變。購買仍使用原收款 action／音樂 checkout，沒有改成 GET 寫入。名單同步尚未完成時，繳費選單停用，避免點擊後無聲返回。

## 方法與資料

免費 Playwright 正常登入，使用同一 Preview alias、隔離 Supabase `ttworfzgwejdeolegkxl`、相同自有測試學員／A10方案，先量修正前再量新版。不是模擬 server action，也不是正式店資料；未改動 DDL、正式環境或共用權限快取。

本輪資料前綴 `qa-auth-perf-20261028-24e72f`。兩店各一位 OWNER、一位學員、一個A10方案、課堂與未繳費預約；另有音樂限制權限 STAFF。帳密及暫用分享入口只在私密 `/tmp`，不納入證據。隔離課堂是 SQL 準備的前置條件，不算本輪重新驗收排課介面；購課、收款及點名仍走真實前後端。

基準前置資料曾出現兩類準備錯誤，失敗檔保留：複製已下架方案而未啟用，以及運動課缺少 `SportsStagingSessionRule`。先核對交易數再修正自有前置資料，不重送已成功購買、不改寫卡餘額或流水。運動第一筆購買成功但沒有保留 UI 耗時，第二筆保留確認耗時但餘額等待失敗；只有第三筆為完整有效前置條件。這些部分完成樣本不得當成完整流程通過。

每次購買10堂／1000，人工 CARD 收款，不經外部支付。每店修正前3筆、修正後3筆；運動最後一筆在第二階段候選完成，音樂6筆均在第一階段及基準完成，不重標為最終候選重新購買。測後核對交易、收入與卡片，不刪除帳務紀錄。

`optionsMs` 是點選更多至購課表單可見；`checkoutMs` 是按確認至視窗關閉；`visibleBalanceMs` 包含等待名單餘額、狀態及 network idle 的收尾時間，不能當作精確首次繪製時間。樣本少、經測試網路代理，不能推定正式環境冷啟動、p95 或保證每次耗時。

## 第一階段發現

第一階段後端已出現 `writeStore.reused: 1`；運動較暖購課樣本後端1093ms、transaction116ms，證明可減少重複確認，但不能直接等同畫面完成時間。音樂既有 dedicated checkout 本來已共用身分，不能把它原有最佳化算成這輪新增收益。

第一階段音樂購課視窗關閉2372／2358／2378ms，沒有比基準2364／1864／1857ms更快；方案選項甚至出現10543／14532ms。比對瀏覽器 action 時間、前後 action 及後端計時，確認讀取 Server Action 會與其他介面 action 排隊；因此沒有以第一階段宣告效能完成。

運動第一階段只完成兩筆購買（40、50堂），第三次點繳費時原本 `purchasePending` 還在收尾、handler 直接返回，等待視窗逾時。SQL核對5筆總購買／50堂後，保留 `sports-identity-optimized-partial.json`，後續僅補尚未購買的第六筆。這是原有同步期間可點擊但無回應的問題，第二階段補停用狀態；不重送已成功的兩筆。

第二階段只讀比較另用 `options-before`／`options-after`，各店相同學員、相同方案與三個視窗尺寸，沒有為開表單量測新增收款。`options-before` 在9d38c0f6：運動5476／4439／1411ms，音樂8504／1940／1443ms。此組與修正權限前的 baseline 分開，不混算。
