# 音樂沿用共用收費介面

音樂與運動的原生收費表單共用同一組收費／體驗／授課分區與CSS；窄容器切換、寬容器並排，標題與取消／儲存固定。單次提供體驗價、體驗時間、獨立體驗店家成本；多次保留每期堂數與每期金額，沒有體驗分區。音樂窗寬1120、高度上限760並受可見視窗限制。

音樂差異維持：堂數制、購買時選期數、編輯既有多期方案保留期數及贈送堂數、每期效期、合格教師的單筆收費限制與教師拆帳比例。沒有運動開放選課、通用卡、點數或共卡操作。資格在教學項目管理，此處不改全項目的資格。

一般與體驗成本直接顯示，沿用 profitEnabled 的可用範圍。音樂一般成本從草稿儲存，體驗成本存既有 chargeSettings JSON，使用上一版既有排課與收款快照流程，無migration。預估利潤明示「未扣教師費」，不取代原教師計酬、實收、分次收款或月結分潤規則。

原生收費的普通未儲存提示不額外占一列，過期版本提示仍顯示；草稿保留、未儲存關閉檢查與未知儲存結果維持原流程。窄／寬切換不卸載欄位。

## 驗證

- 10 files / 89 tests通過，含音樂期數、贈送堂數、有效期、單筆教師範圍、拆帳比例、一般及體驗成本、免費體驗、原生運動回歸與顧客編輯。
- 更新原本以標籤順序找售價的測試，改找具名price欄位；教師資格測試改驗已具資格教師的單筆限制，不再期待把無資格教師加入全項目。
- TypeScript、變更ESLint通過。
- 真實元件本機Chromium fixture：390×650、390×844、768×1024、1024×768、1366×900，各驗單次與多次，共10組。一般／體驗成本可見、利潤180、沒有運動專用欄位、內容無溢出、儲存可見、切換保留輸入。長教師名單自身捲動。
- fixture拒絕交易，未對正式店家建立訂單或更改卡片，並非完整正式登入交易驗收。小鍵盤／極矮視窗仍保留必要捲動。
