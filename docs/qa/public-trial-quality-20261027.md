# 運動／美業公開體驗預約品質提升

## 需求與範圍

使用者要求運動與美業的公開體驗預約達到蒸足版的對外呈現品質。以既有蒸足公開頁的品牌介紹、清楚選擇、預約確認及到店資訊為基準，新增兩模組共用外框，保留不同的預約、名額、體驗、身份與通知規則。

受影響入口：`/sports-trial/[slug]`、`/beauty-trial/[slug]` 及導向這些表單的既有 LIFF 公開入口。蒸足表單、會員預約、店家設定及音樂模組不套用本次新外框。

## 最終行為

- 共用品牌頂列、體驗介紹、實際體驗費用與時長、三段預約流程及預約後到店資訊。資料來自本店既有 catalog / presentation，不顯示其他店家地址、價格或圖片，也不虛構原價、折扣、照片、付款承諾或通知送達。
- 運動：以課程卡片選課，接月曆及當日課程時段／剩餘名額。切換課程清除不適用的日期與 session，保留聯絡草稿；確認頁顯示日期、時間、時長、人數、地點及體驗費用。沿用第一階段後端體驗服務，僅加上 template ID 供前端分組。
- 美業：可選的服務卡片直接顯示本次體驗時長及價格；日期改用共用月曆，保留手機資格查詢、技師安排、同行者逐人服務、獨立聯絡人及備註。未查詢的日期只代表可選日期，不宣稱有可用名額；時段仍由既有後端查詢產生。
- 保留相同 requestKey / payload 重試、不明送出結果鎖定資料、美業僅修復 LINE 通知連結的恢復流程，以及通知是否連結與實際送達的區分。
- 到店資訊及常見問題沿用共用骨架，取消規則以各店設定為準。沒有增加會員專區操作指南。
- 初次開啟保留品牌頁頂端；變更步驟後移動焦點到表單標題，避免手機停留在前一頁底部。尊重減少動態效果設定。

## 驗收結果

- 10 個相關 Vitest 檔共 96 項通過：月曆、公開美業 UI、運動服務與門市隔離、LIFF 入口、會員登記及課程期限。
- 最終 TypeScript `--noEmit`、修改檔 ESLint（零警告）與 `git diff --check` 通過。
- 實際 React 元件隔離瀏覽器驗收：`scripts/qa/public-trial-quality-browser.mjs`。既有美業與運動 QA 命令共用此腳本。
- 360×800、390×844、768×1024、1024×768、1366×900 共 45 張狀態截圖，涵蓋兩模組介紹、選擇、確認、成功及美業多人確認。沒有整頁水平溢出，聯絡輸入字體至少 16px；既有主要控制維持觸控尺寸。
- 驗證課程切換、日期／時段選取、返回／縮放保留草稿、長服務名稱、多人體驗費用與時長、指定技師、不明結果重試、通知連結恢復、未驗證／空資料／關閉狀態。
- 逐張檢查發現舊共用 CSS 使運動選取卡片白字落在淺底，已修正並加上選取文字至少 4.5:1 的瀏覽器對比檢查。輔助文字及小標亦加深。

證據在 `evidence/20261027-public-trial-quality/`，包含 `results.json`、45 張截圖及可獨立開啟的合成資料 `preview.html`。後者只包含範例 handler，可切換運動／美業；不會建立實際預約。

## 限制與發布

隔離預覽封鎖外部請求，使用合成 catalog、門市資訊及提交 handler；不代表正式店家、LINE 客戶端、實際名額交易或通知送達驗收。未改正式資料、開放選課／體驗開關、通道環境變數或圖文選單，未執行資料庫遷移。

本次尚未正式合併／發布。依 AGENTS.md「未取得使用者明確授權，不得合併正式站」。發布後仍需從實際官方帳號，以經授權的單筆預約核對兩模組各自的後台結果及 LINE 通知狀態。銀百合若未開放公開體驗課，仍顯示沒有可預約課程，不自動開啟指定學員課程。

## 追加：手機視覺精修

依使用者要求再提升整體質感，精簡 hero、移除重複的外部三段流程及介紹段落，保留表單當下步驟。課程／服務卡改為項目與時長靠左、金額與選取標記靠右；減少字重與邊框負擔，保留清楚的文字對比及主要操作尺寸。運動初始重複標題改為僅供輔助工具讀取，步驟切換焦點仍保留。

地址與聯絡／導航直接可見，到店準備改為原生 details 可展開，減少未預約時的閱讀負擔。沒有借用其他店家照片，也沒有新增虛構的門市素材。

精修後相關 UI／月曆 20 項回歸測試、TypeScript、修改檔 ESLint 與 diff 檢查通過。共用瀏覽器腳本再次完成五尺寸、45 畫面、選取文字對比及原操作驗證；結果新增首張選項距頁首位置供後續比較。截圖與互動 preview 已更新為精修版，仍為封鎖外部請求的合成資料預覽，未發布正式站。
