# 運動空間列表操作修正

新版運動入口已啟用，但 CourseRoomsPage 未傳 sportsNative，空間列表仍呈現舊操作列。舊列的查看、狀態與課表按鈕超過 72px 操作欄寬度，造成右側裁切與編輯入口不明顯。

空間頁現在沿用店家的 sportsNative 判斷。可編輯帳號直接看見「編輯」按鈕；其他操作沿用共用選單。頁面補齊 w-full/min-w-0，表格局部水平捲動，空間操作欄固定在右側。未改權限、資料庫或交易儲存方式。

受影響入口：運動／音樂及共用空間列表；僅已啟用原生運動或音樂的列表新增直接編輯。唯讀模式仍無編輯權限。

驗證：9 項測試通過；TypeScript 與變更檔 ESLint 通過。實際 CourseWorkspace 的合成資料 Chromium 預覽於 1440×900、1366×900、1024×768、768×1024（均含 220px 側欄）檢查無整頁水平溢出、44px 編輯操作可見、可開啟編輯表單、旋轉後無溢出，以及唯讀模式無編輯按鈕。預覽中的所有交易 action 拒絕執行，未提交正式資料；不代表實體 iPad Safari 或正式登入交易已驗收。
