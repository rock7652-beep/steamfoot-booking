# 運動收費：體驗店家成本與配置

指定學員的單次收費新增獨立「體驗店家成本」。體驗價與成本並列，時間與體驗預估利潤放在同區；手機／窄容器分成收費、體驗、授課三區，寬容器三欄並排。多次方案不提供體驗設定，開放選課仍使用原店家體驗規則。原成本權限保持不變，音樂及美業介面不套用本次新配置。

## 資料與儲存

- JSON chargeSettings 加入 optional nullable trialStoreCost，不需資料庫 migration；舊設定未出現此鍵時仍可讀取。
- 留白是未設定，不繼承一般成本，利潤顯示 —；0 是明確零成本。體驗成本需先有體驗價；負數、小數及超出範圍拒絕。免費體驗可設定實際成本並顯示負利潤。
- 修復 saveSportsFee 遺失一般 storeCost 且固定寫0的問題；UI實際值送至現有收費儲存端，未傳成本時保留既有 snapshot。
- 排課 quote 保存當下設定與一般成本，體驗收款 audit 保留該課次體驗成本及實收減成本的快照，不讀後來調整的方案成本。收款重送不改寫快照。
- 不回填既有排課或已收款歷史；不改現金實收、退費、教師計酬或月結分潤規則。體驗成本此次記錄於既有課次 JSON／收款 audit，不新增帳務欄位或自動分帳。
