# 運動收費成本與視窗配置

使用者要求店家成本不再藏於更多設定，並減少整個視窗往下捲動。新版運動收費改為「收費設定」與「授課設定」兩區，窄視窗切換且保留草稿，寬容器並排。售價旁直接顯示成本，單價及預估利潤直接顯示，仍依既有 profitEnabled 權限提供成本。

收費視窗固定標題與取消／儲存，桌機高度上限760px並受可見視窗限制。一般表單不需整窗捲動；長授課名單有自身88px捲動區。小螢幕鍵盤、錯誤訊息及極窄尺寸保留可捲動作為操作保障，不裁掉欄位。其他模組與舊表單不套用新的分區。
