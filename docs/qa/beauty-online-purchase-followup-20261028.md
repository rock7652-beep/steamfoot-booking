# 美業線上購買相容性盤點

此工作已有預設關閉的候選實作，方案購買意圖及會員申請意圖開關必須維持關閉；不能將本記錄視為開啟或正式上線的驗收。遠端資料庫尚未遷移，本次修改尚未部署。

## 已確認的問題與修正

- 原會員申請的識別碼僅存在元件記憶體，回應遺失後重整可能重複建立訂單。候選新增伺服器意圖、同分頁識別碼恢復、取消墓碑及明確確認；沒有可購方案時仍有獨立核對入口。另一裝置無法看到尚未到達伺服器的請求。
- 會員端曾將所有非待核帳狀態顯示為已核帳。本次改為區分待核帳、已核帳、已作廢；未知狀態顯示待確認。此 UI 修改尚未部署或完成手機／LIFF 驗收。
- 同一請求已成功但回應遺失後，店家若移除銀行設定，舊程式會先因缺少銀行設定而拒絕重播。本次將銀行設定檢查移入新申請的 command 工作函式，已記錄的同一請求仍由 command 的身分及內容比對控制重播；新申請仍需銀行資料。測試使用 command 替身，尚非完整交易端到端驗收。
- 候選申請對顧客看到的方案名稱、價格、次數及版本建立指紋；在同一門市鎖內建單前比對當前方案，變動時停止建單並提示聯絡店家。已匯款不代表申請或核帳成功。
- 候選後台可對既有 PENDING 訂單恢復核帳狀態，並在未明確確認前保護相關退款／作廢。線上核帳與直接購買的未確認卡片共用保護；原發卡、收款及更正保留交易語意。

## 未完成及必須驗收

- 在固定版本完成會員與後台的真實登入端到端測試，包含已送出後回應遺失、重整恢復、無商品入口、原價改變及不同裝置；既有方案也須驗證能安全完成核帳。
- 核對舊版程式與在途請求的切換、取消與核帳競爭、權限及跨門市隔離。另一裝置無法看到尚未抵達伺服器的請求；不得宣稱完全跨裝置防重。
- 以隔離測試資料驗證實際扣款帳簿、重送、回應遺失、重整、作廢和遲到請求，並完成會員前台手機／LIFF 及後台桌機／iPad 驗收。前述修改均未套用至遠端。

## 本機驗證

固定候選程式的 13 檔重點測試共 83 項通過；涵蓋會員／後台的動作授權、狀態介面、重整、原請求取消、方案變動及舊訂單。TypeScript 與修改檔案 ESLint 通過。

以僅綁定 127.0.0.1 的一次性 PostgreSQL 執行會員與方案意圖測試，17 項通過；隔離測試庫已停止移除。另有收款測試因未開啟其獨立測試條件而跳過 4 項，不應計為通過。這些資料庫測試使用實際狀態服務、migration 和局部 SQL adapter；並非真實 LIFF 或完整帳簿端到端。
