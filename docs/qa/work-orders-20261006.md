# 工單管理 — 2026-10-06

## 實作

- 工單是獨立功能與獨立 HQ 授權，入口不放在進銷存中。先由 HQ 明確啟用，不新增方案費用或自動替既有門市開通。
- 使用 Framework 清單、共用 ModalPanel、RosterToolbar、CustomerInstantSearch；同頁新增、編輯、更新進度、收款；顧客可原頁快速建檔。
- 以同一筆 InventoryOrder 作為唯一單據；workOrder JSON 只保存非金流案件內容。銷貨列表標示工單與進度；銷貨編輯器拒絕修改工單。
- 工費預設0，不設店家金額上限；數值仍需符合目前資料庫 Int 儲存範圍（最高2147483647元）。工費保留為非庫存品項，開單預設未付款。
- 處理中／待取件／已取件與未付款／部分付款／已付清分開。0元新工單仍顯示未付款；0元已取件顯示免收費。已取件不直接改內容，先改回處理中；取件不自動視為已收款。
- 搜尋姓名、電話及完整單號；後端每頁50筆，進度與付款篩選套用完整結果後才分頁。搜尋回應以版本排除過期結果。
- 商品沿用庫存與價格權限；需要進銷存授權及 inventory.write。費用單獨可用，不依進銷存開關。商品選擇目前最多載入1000個啟用品項。
- 收款共用 InventoryPayment／CashbookEntry／現金抽屜鎖；Store鎖串行化唯一請求、欠款及庫存。只取既有商品庫存差額，不因付款／取件重扣。
- 工單自己的收款記入工單收入；混合銷貨批次仍走既有共同收款來源，不新增第二份金流。
- A4橫向左右各一份A5顧客聯／店家聯，內容不包含商品成本及內部備註。長文字保留完整內容，可能跨頁，不能靠裁切避免多頁。
