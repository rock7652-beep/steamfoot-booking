## 問題對應

| 問題 | 修改 |
| --- | --- |
| 顧客總覽逐段讀取 | 沿用當頁／intent 預讀；card-read 同一回應準備方案與進度、先安裝進度快取；下次預約／音樂概況同步預讀，開窗直接使用已有快照；詳見 `customer-overview-preload-20261112.md` |
| 舊 OPEN 通用課卡誤示科目待核對 | 僅在原有 OPEN 卡沒有解析出適用方案項目時提供核對入口；已有明確 scope 的卡不再警示，不改餘額、效期、資格或已售約定 |
| 教師分頁與授課時間重複 | 原生音樂／運動共用四個層級：基本資料、授課設定／授課與拆帳、授課時間與課表、工作權限與 LINE；工作分頁移出時間與課表，時間分頁只掛載一份可授課時間；保留外部 adapter 既有分頁 |
| 教師授課設定等待 | 原生入口開窗即開始讀取，pointer／focus／touch intent 共用在途；staff-teaching-read GET 避開瀏覽器 Server Action 排隊，保留 TTL 0、店家／角色／費率讀取權限；獨立資料庫查詢並行，保留草稿與重試 |
| 操作列與新增按鈕不一致 | 運動／音樂清單搜尋及篩選靠左，新增靠右、綠底白字；移除新增操作文字的加號、教師／人員互相跳轉及返回教學項目的頁面快捷入口；保留全域店家與帳號選擇 |
| 操作表頭與 ⋯ 偏移 | 收費清單操作欄固定同一欄寬，表頭及按鈕均置中 |
| 第一頁混入下架方案 | 先排所有上架、再排下架，合併為同一個每頁 20 筆的分頁集合，不再逐頁附加下架區塊；當頁選取與分頁數使用同一集合 |
| 篩選後／跨頁無法排序 | 允許在搜尋／篩選中移動同組方案；「調整順序」暫時展開目前篩選的全部結果，拖曳及鍵盤沿用即時儲存；完成後回原分頁。未顯示項目不丟失，鍵盤只找目前可見的同組項目；不以排序變更教學項目或上下架狀態 |

教師月結「待核對」另經唯讀確認為尚有學員待點名，使用者已理解；此處不改點名、零元交易或教師計酬規則。原價／固定費用與既有授課快照保留。
