狀態：本機待審查，未推送、未合併、未部署。停止所有資料庫寫入與重試；本次沒有執行資料庫變更，也沒有建立備份或演練還原。

## 本次程式變更

- 刪除舊 SPA 頁面、API、設定儲存路由、提醒工作、專用 Prisma client/schema、開店種子及發佈工具。
- 共用查詢移除舊 SPA client、SpaBooking 聯集、示範店功能與權限繞過；背景工作與門市切換清單排除舊 SPA。

- 封鎖舊 SPA 專用 production migration target；移除其 reconciliation/deploy 呼叫。歷史 migration SQL 與資料庫內的資料不變。
- 新版美業另於 `fix/beauty-hours-selected-dates` 分支修改共用時間讀寫與門市邊界，保留 BEAUTY 支援；沒有將主站整份刪除變更直接覆蓋美業分支。
