# 課名內部尾碼全站呈現盤點與修正

## 問題與規則

使用者回報 `83f866` 仍出現在課名，要求全站不顯示這類代碼。原 sportsCourseName 只在 sports_item／sports_rule 的 64 位模板 ID 及名稱末六碼完全相符時隱藏；首頁待處理、歷史與若干入口仍直接回傳原始課名。舊快照無模板資訊或換過模板時也會漏網。

共用 courseDisplayName 將課名末端 ` · 六位十六進位碼` 視為內部辨識尾碼，包含大寫與連續尾碼，統一移除；不要求目前模板 ID 相符。既有 sportsCourseName 呼叫沿用同一函式。一般課名、QA 日期、中文班別、名稱中段代碼保留。模板清單的 name 與 ID 仍保留，displayName／標籤清理；沒有執行資料庫批次改名、migration、真實顧客操作或帳本修改。

## 入口對照

| 入口 | 修正邊界 |
| --- | --- |
| 課表初次載入、背景刷新、當日課表、單堂編輯、會員課表／預約、授課工作頁 | 原共用 sportsCourseName 改用新規則，既有呼叫生效 |
| 模板清單、課程選單、設定檢視／編輯與複製、音樂排課精靈、教練授課費欄位名稱 | 共用模板標籤及輸入／複製前課名呈現 |
| 首頁今天待處理 | 只清理 attendance 類課名；顧客跟進及購買標籤保留 |
| 會員方案上課歷史、後台顧客歷史、已預約占用明細 | 各授權讀取回傳名稱；時數、額度、狀態與 ID 不變 |
| 補課時段、會員／教師改課、工作課次詳情 | 回傳課名與候選名稱 |
| 空間使用、教練交接與儲存後交接快照、排課衝突與值班錯誤 | 課名 DTO／錯誤明細，不改授權與衝突判斷 |
| 營運體驗收款、課程匯出、未結算授課費 | 只清理課名欄位，不改收款編號、金額或計算 |
| HQ 操作紀錄 | CourseBooking／CourseSession／CourseTemplate 的對象顯示標籤，內部 target ID 保留 |
| 後台異動通知及詳情 | 讀出既有通知時清理 courseName；整堂課通知的 customerName 實為課名，也清理 |
| 會員課前提醒、教練 LINE 摘要、當日新增通知、候補通知 | 只格式化課名文字；未啟動或發送通知。已送達外部歷史訊息不回寫 |

租借者、顧客與教師姓名不套用課名清理；購買快照、帳本及實際識別碼不變。內部模板名稱仍可含防重名尾碼，由 UI 格式化隱藏，避免破壞 storeId＋name 唯一約束。
