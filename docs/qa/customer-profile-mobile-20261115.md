# 顧客基本資料位置與手機日期欄位（2026-11-15）

使用者以手機正式畫面驗收後，確認歸屬店長、推薦人與編輯入口應放在電話／LINE下方的可捲動基本資料區，四模組只保留一組。另發現蒸足固定區占用大量手機空間，補登及調整期限的原生日期控制超出表單邊界。

## 修正

- 共用 CustomerProfileIdentity 集中基本欄位與原模組歸屬編輯；移除方案下方的原位置，維持既有修改權限與音樂店長欄位限制。
- 蒸足沿用共用姓名表頭，聯絡、歸屬、標籤、常用操作與分頁移入原捲動區；保留原 body/header ref、讀取、載入追蹤、pending保護與返回流程。備註與全部紀錄的順序對齊其他模組。
- 四模組共用補登／期限表單採用有寬度邊界的原生日期控制，保留native picker、aria label、min/max與disabled狀態。日期文字16px、觸控高度44px；窄容器表單換成單欄，保留正常字級。
- 不修改額度預覽的數字口徑、交易port、扣堂、計酬、付款、資格、權限、通知或schema。
