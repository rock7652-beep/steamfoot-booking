# 公開體驗頁可讀性與銀百合導航修正

使用者反映銀百合公開體驗頁顯示竹北市勝利十一路72號，但導航到其他地址；手機文字偏小。

## 修正範圍

- 正式 ShopConfig 的銀百合 mapUrl 原短網址實際轉往「新竹縣竹北市北興里十興路235巷31號」。依使用者確認的頁面地址，僅將 store-silverlily 的地圖目的地修正為「新竹縣竹北市勝利十一路72號」，以舊網址與地址作條件更新，回讀確認一筆。地址文字與其他店家設定不變。
- 運動及美業共用體驗頁正文、地址、說明、FAQ、操作文字與聯絡資料標籤調為16px；行事曆補充、費用／時間標籤、步驟數字與頁尾至少14px。移除手機10–13px縮字。日期格增高並保留換行。
- 增加局部選擇器優先度，避免既有 course-portal 全域正文與 summary 的13px 覆蓋新字級；不改會員前台全域樣式。

## 驗證

既有隔離瀏覽器流程擴增文字最小尺寸檢查及空狀態截圖，360／390／768／1024／1366，共50張狀態截圖。通過無水平溢出、可見文字至少14px、輸入16px、選中對比；運動選課／保留草稿／重試／成功頁，美業多服務／多同行者／指定技師／重試／通知連結恢復均正常。資料為合成且封鎖外連，不建立正式預約，非真人LINE與實機Safari驗收。

證據：evidence/20261027-public-trial-readability/results.json 與對應截圖（本地工作目錄）。目視檢查手機空狀態及iPad確認頁。

正式發布延續使用者先前已授權的正式上線與本次修正請求。發布後唯讀檢查銀百合實際頁面的導航href與computed font-size。
