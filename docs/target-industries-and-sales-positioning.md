# 蒸足系統可開發客群與銷售定位

## 一、核心定位

蒸足系統不只是預約系統，而是服務型門市的顧客經營系統。

適合有預約、方案堂數、顧客回訪、LINE 溝通、店長管理需求的門市。

核心銷售句：

> 不是只幫你記預約，而是幫你管理顧客、降低漏約、提高回訪、看懂營收，讓店長從每天忙現場，變成真的會經營店。

## 二、最適合開發的行業排序

| 優先順序 | 行業 | 適配度 | 原因 |
| --- | --- | --- | --- |
| 1 | 蒸足 / 足浴 / 養生館 | 最高 | 預約、方案堂數、回訪、LINE提醒、健康摘要、月結管理都高度吻合。 |
| 2 | 按摩 / 指壓 / SPA / 芳療館 | 很高 | 有預約、技師或服務人員、方案堂數、回訪、現金管理需求。 |
| 3 | 美容 / 美體 / 臉部保養 | 很高 | 重視續購、回訪、顧客追蹤與方案管理。 |
| 4 | 運動教室 / 私教 / 皮拉提斯 | 中高 | 有課程預約、會員堂數、教練排程與回訪需求，但團課邏輯可能需要後續調整。 |
| 5 | 美甲 / 美睫 / 紋繡 | 中高 | 預約與回訪需求明確，但未來若要更貼近此行業，可能需要作品 / 照片紀錄。 |

## 三、不建議優先開發的行業

### 餐飲業

不適合。需要桌位、點餐、翻桌、外送、POS，和目前系統差距較大。

### 零售店

不適合。重點是庫存、商品、POS、會員點數，不是預約與堂數。

### 大型醫療院所

暫時不適合。合規、病歷、掛號、保險申報過於複雜。

### 大型連鎖品牌

暫時不優先。通常要求客製、API、資安、SLA 與企業合約，服務成本較高。

## 四、最佳潛在客戶特徵

- 有賣套票 / 方案 / 堂數
- 有 2 位以上服務人員
- 每天預約超過 5 組
- 主要靠 LINE 跟顧客聯絡
- 有顧客回訪與續購壓力
- 店長不知道誰快到期、誰很久沒來
- 未來可能開第二家店
- 目前還在用 LINE / 紙本 / Excel 管理

一句話判斷：

> 只要這家店有「預約 + 回訪 + 堂數 + LINE」，就是潛在客群。

## 六、主推方案建議

目前建議主推「專業版 $2,490 / 月」。

原因：

專業版價格容易接受，且能提供店長最有感的顧客經營、現金抽屜、工具型模組與經營型模組。
