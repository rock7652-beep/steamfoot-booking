# 三模組操作即時化

## 驗收標準

- 搜尋已載入資料立即篩選；分頁或補查尚未完成不得顯示確定「查無資料」。
- 操作當下顯示儲存中；成功、明確拒絕、連線結果未知分別呈現。
- 明確拒絕還原原值；連線結果未知不得盲目重送。
- 防連點以同步鎖實作；不同資料列可以獨立儲存。
- 列表、明細與摘要一致；扣堂、金額與名額以伺服器確認為準。
- 更新保留搜尋、篩選、日期、捲動與未儲存輸入。
- 舊請求不能覆蓋新結果；快取需隔離門市、模組與權限。
- 批次操作逐筆回報；成功項目不可隨失敗項目一起重送。
- 已成功操作的更正走正式業務流程，不只是回復畫面。

## 本分支已實作

- 共用 useResponsiveAction：逐筆同步鎖、儲存狀態、明確失敗還原、未知結果鎖定。
- 營運顧客待辦：狀態變更失敗恢復完整舊紀錄；備註失敗保留輸入並顯示錯誤；儲存中保留篩選中的該筆。
- 方案啟用與公開購買開關：立即預覽新狀態，成功後更新父清單；失敗還原。
- 課程名單：讀取版本保護、寫入期間暫停背景覆寫、同步防連點、結果未知禁止再次操作。

## 尚待接入與驗收（不可宣稱已完成三模組）

- 蒸足預約到店、未到、取消、更正：逐筆處理狀態與明細/摘要同步。
- SPA 新增、取消與改期：局部更新與技師/位置衝突失敗回復。
- 課程點名、請假、曠課：逐筆狀態、批次部分成功、老師/學員狀態一致。
- 三模組顧客編輯、人員、教室、服務位置、提醒設定的共用更新。
- 現金收支確認成功後局部更新，合計不計入未確認紀錄。
- 跨頁搜尋資料完整性、快取失效、切換門市清除舊資料。
- 真實後台桌機/iPad及顧客/教練LIFF流程验收。
