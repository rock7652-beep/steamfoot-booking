# 音樂教師編輯第二輪簡化

## 變更

- 基本資料：固定身分改文字，緊急聯絡人姓名／電話／關係集中；通知資訊移至 LINE 頁。維持緊急聯絡人必填規則。
- 授課與拆帳：取消預設／彈性二層頁籤；先選課程，再顯示共同分潤與可收合的個別調整。不因修改共同比例清除既有個別規則，保留 null 與明確零的差別。
- 課程保留搜尋、科目、已選／未選篩選、批次勾選；批次操作標明篩選結果數量，已选課程集中列出。
- 分潤摘要依班型定價試算每堂金額；不是含折扣／贈課／結算快照的實際薪資。沒有定價時只呈現比例。費率資料沿用原權限檢查。
- LINE 與權限：綁定老師 LINE；未選帳號收起可用功能但保留原值；授課時間及已排課次收合。
- 清單顯示可教課程數與 LINE 綁定狀態，點擊直接開對應頁籤。
- 移除音樂表單底部重複取消；新增按鈕為新增教師。關閉有修改才顯示繼續編輯／放棄修改；搜尋及篩選不算修改。
- 儲存結果即時套用清單，剛儲存資料不因原篩選隱藏；保留其他人員模組的按鈕及關閉流程。
