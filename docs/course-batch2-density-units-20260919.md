# 第二批介面回饋：扣抵單位、側窗與可教授課程

功能版本：bc111ba2（包含 b129b4ae 的點／堂扣抵顯示及回歸測試）。本輪不修改首頁、正式資料库或下一批金額功能；無資料遷移。

## 修正

1. 新增／查閱／編輯課程及排課說明：點數卡按設定點數，堂數卡每人每次 1 堂，兩者不互斥，仍受方案適用課程與期限限制。預約占用，出席才扣抵。
2. **查明並修復實際缺口**：後端原已依卡片單位扣抵，但後台名單代約選單一律以課程點數判斷可用餘額，造成剩 1 堂的卡無法預約 3 點課程。已改按卡片單位判斷，名單及餘額也以點／堂顯示。未改寫任何既有卡片或歷史紀錄。
3. 課程／教室／排課側窗縮減標題、說明與欄位間距，移除新增表單上方大型說明框，保留 44px 觸控及固定操作區。人員側窗使用既有 compact 層級與淡色框線，分頁有持續綠色選取狀態，基本短欄位並排。
4. 可教授課程支援真實名稱搜尋、多選與已選數量。一般設定直接隨人員儲存，不再有第二次確認。舊人員只改無關欄位維持待補狀態；調整可教授課程才確認，保留舊課過渡規則。
5. 新增店長在其他分頁按儲存，缺少必填登入資料時會切回對應欄位，隱藏頁不再妨礙驗證與聚焦。純教練不渲染後台必填欄位。

## 真實隔離驗收

使用一般店長，非 HQ；新增專用測試人員與扣抵資料，原資料保留。

| 驗收 | 結果 |
|---|---|
| 純店長、純教練、店長兼教練新增／儲存／重開 | 三種均通過；登入資料、緊急聯絡依既定要求；純教練不需要後台密碼 |
| 可教授課程搜尋、多選、儲存 | 通過；沒有第二次確認欄位 |
| 舊教練未調整可教授課程而儲存 | 真實網頁儲存成功；資料庫確認仍為待補，未誤確認空白資格；直向固定操作可觸及 |
| 儲存可教授課程後進新增排課 | 可選到對應教練，通過 |
| 後台 3 點課程使用僅剩 1 堂的卡 | 選單可選，預約成功，快照為 1 堂 |
| 點數卡預約／報到 | 原剩餘 10 點不變，占用 3 點 |

| 桌機／iPad 尺寸側窗 | 1440×900、1024×768、768×1024；課程、教室、排課標題／第一欄／底部按鈕 hit-test 通過；人員標題及底部操作通過 |

扣抵測試的課程、方案、卡片與學員由隔離 fixture 建立，不冒充購買核帳測試。預約、取消、重約、報到與出席由實際網頁完成，重送透過同一登入的相同已捕捉請求；後續 SQL 唯讀核對餘額與紀錄。為測出席時間限制，僅將本次 fixture 課次由未開始調為進行中，未更動其他課次。沒有發送 LINE／Email。

本機相關 50 項測試、型別與修改檔 lint 通過。bc111ba2 的 Vercel 部署、Changed-file ESLint、Typecheck、Full Vitest baseline、Targeted tests 與 postgres-integration 均通過；Cloudflare 保持豁免，不能記為通過。暫存服務測試因本機隔離 DB 連線值空白未執行，已改用正式可用的受控資料工具及網頁完成上列驗收，未繞過安全限制。

## 報酬／拆帳尚未實作

「可教授課程」僅控制排課資格，不能代表合作或金額設定完成。本批無可儲存的假報酬欄位。

後續依已確認金額批次，將在人員側窗的「合作設定」集中處理授課報酬、方案分潤與空間費，選用才展開；月結／付款入口位於營運。承接已確認的單堂約定→個別課程→課程預設優先序，未設定與零元分開；一次／按堂分潤、折扣負擔、獨立或抵扣空間費、同人兼任不自動重複給付，以及月結版本、部分／分次付款與跨月調整。這些不屬本輪完成項目。
