# 即時操作驗收（預覽限定）

## 本輪修改
- 共用 GET 即時篩選：課程營運、一般營運、交易、健康紀錄。文字250ms、選項即時、完整日期區間驗證、保留捲動。
- 顧客列表：篩選期間不鎖定選項，累積連續修改，移除課程搜尋送出按鈕。
- 課程顧客選取器：經 courseManager/customer.read 與門市可見範圍載入最多2000筆輕量搜尋索引；超出時仍查伺服器，不把快取當完整資料。只保存在掛載元件，不跨登入持久化；焦點返回、資料異動重新載入。舊回應與不同路徑結果不顯示。
- 學員持有方案：查詢保留原列表，更新中不可選取舊結果。
- 方案/課程/教室單筆及批次狀態樂觀更新，失敗還原；人員權限仍等系統確認。
- 學員備註可立即呈現儲存內容；衝突/失敗保留草稿並還原。
- 購買成功後，快取失效排至回應後，不把交易完成後的頁面同步納入收款等待。

## 自動驗收
107項測試通過（搜尋、完整/不完整索引、IME、立即篩選、日期、狀態還原、批次服務、備註衝突、拆期優惠、結帳防重複等）。完整 TypeScript 通過。修改共用元件 ESLint 通過。

## 瀏覽器驗收
待本次預覽部署後補入。不得把自動測試當作桌機/iPad或真實慢網路通過。

## 保留規則及限制
- 交易仍等伺服器確認，不樂觀增加付款或堂數。
- 原有出席/排序樂觀機制保留，未重寫。
- 目前尚有背景 router.refresh 作最終同步，並非全站完全取消整頁讀取。
- 索引初次載入仍需網路；無完整索引時使用伺服器結果。
- 身分合併預覽是明確操作，不作自動執行。
- 正式站不合併；沒有新增資料庫 migration。
