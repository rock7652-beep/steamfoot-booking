# 音樂模組稱呼與初始設定盤查

## 已確認的設定依賴

引導順序：營業時間與公休 → 空間 → 課程 → 方案 → 教師與授課資格 → 第一堂課。

- 排課真正依賴啟用的空間、可使用的課程與啟用且具該課程資格的授課人員。
- 排課／複製／調課會核對營業與公休、教師可授課時間、教師／空間撞期。整堂課須落在同一有效營業區間，不只核對開始時間。
- 未設定任何教師可授課時段時沿用店家營業時間；已有自訂週表時，未設定的星期視為不可授課；單日休假或自訂可覆蓋週表。
- 值班聯動開啟才要求值班涵蓋完整課程；引導顯示此條件，但完成授課資格不等於任何日期的值班已準備好。
- 音樂課另檢查課程長度、整點／半點開始、不可跨日。音樂課程／方案需依現有課型、每堂價、堂數、效期與期數規則設定。
- 方案是學員購買／預約使用的產品；建立課表本身不要求先建立方案。音樂方案可先於教師建立；一般方案不預先綁定教師或固定課次。
- LINE 綁定、銀行資訊、授課費與月結屬對應功能的設定，不列為建立第一堂課的通用前置。
- 注意：現有後端在完全無營業時段資料時不一律拒絕排課，不能把過去個案直接歸因為「沒有資料必然擋住」。週休、公休、已有時段範圍、教師自訂時間或值班才會產生對應拒絕。本次未更動排課交易規則。

來源：course-resources.ts、course-business-hours.ts、course-availability.ts、course-duty.ts、actions/course.ts、actions/course-members.ts。

## 文案盤查與修改

只處理產品產生的稱呼，不改人員／會員姓名、coachId、role、權限、資料模型或既有紀錄。

- 依作用中門市的 business.music，設定引導與指南顯示教師；運動保持教練。
- 排課／修改／複製提示、課表空狀態、篩選的輔助標籤、顧客詳情／本次備註說明、前台備註與指南、教師管理、提醒分頁／綁定／預覽、今日清單、月結與授課費表頭。
- 顧客與後台指南在權限篩選後、文字搜尋前處理模組稱呼；來源路徑、文章 ID、功能及權限不變。
- 前台載入器用明確 music metadata，不靠是否開放同行預約推測模組。
- 跨模組共用的體驗收款、值班、計酬單位、歷史人員 fallback、後端固定錯誤稱呼及通知失敗紀錄使用「授課人員」。不修改既有已凍結 LINE 重試內容。
