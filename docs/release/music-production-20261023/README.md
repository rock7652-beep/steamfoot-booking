## 遷移失敗與回退

- SQL 包含單次交易、advisory lock、鎖定與查詢逾時，任一步失敗全數回滾；不可把失敗當作已套用。
- 已存在或只存在部分新表時拒絕重跑；先核對既有 DDL 與執行紀錄。
- 若 DDL 成功、程式尚未切換，維持舊程式即可；新表保持空白，不複製測試資料。
- 若新程式產生正式收款後需回退，只回退程式部署；完整保留收據、期別、稽核與新表，不執行 DROP 或帳務反向回填。
