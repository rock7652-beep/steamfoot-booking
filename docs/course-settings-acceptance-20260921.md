# 課程設定五區版驗收

範圍：原 A 店隔離預覽，驗收通過前不合併 main。本批沒有 schema / migration、收費或扣堂規則變更。

## 逐區驗收

1. 店家資料：預設顯示名稱、地址、地圖及官方 LINE 狀態；點編輯才展開欄位。儲存後重新整理，資料仍一致。
2. 營業與預約：核對預約開放範圍、截止時間、值班聯動。修改截止時間不影響店名與銀行資料。營業時間頁返回本分類。
3. 收款與體驗：核對銀行末四碼；修改銀行不覆蓋官方 LINE。LINE 統一於店家資料修改。體驗頁返回本分類。
4. 通知與顧客經營：提醒、關懷、推薦、數位管家入口須同時符合權限與功能開通。子頁返回通知分類；保留顧客關懷原有首頁入口。
5. 系統方案與用量：顯示真實系統方案、訂閱狀態及可讀用量，不混入學員課程方案；不連到含示意訂閱資料的舊方案中心。

## 編輯及手機驗收

- 手機使用分類選單；桌面使用左側五區。一次只顯示一區。
- 店名輸入但不儲存，切到收款後再回店家資料，草稿仍在。
- 儲存失敗或網路失敗保留輸入；儲存中不得重複送出。
- 取消未儲存修改先確認；捨棄只影響本區，不清空其他區草稿。
- 點一般站內連結離開，未儲存時顯示頁內確認；重整 / 關閉分頁由瀏覽器確認。瀏覽器歷史返回的跨頁草稿恢復不在此批保證範圍。
- 以無設定權限 / 未開通功能 / 總部檢視模式帳號核對不可編輯入口。
- 固定期課未到仍扣堂且無補課券；自由預約取消或未到釋放占用，僅修正文案，沒有變更行為。

## 自動檢查與限制

- 分區儲存測試涵蓋欄位隔離、參數驗證、權限及到期攔截。
- UI 測試涵蓋分類、URL 前綴、草稿、儲存成功/失敗、捨棄、重複送出、未開通入口。
- jsdom 測試不等同登入後實頁或手機實機驗收；後者需在預覽另行完成。
