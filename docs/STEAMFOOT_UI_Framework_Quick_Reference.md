# 蒸管家 UI Framework Quick Reference

> 完整規範：`docs/STEAMFOOT_UI_Settings_Framework.md`  
> 本頁只提供開發前快速檢查；若有衝突，以完整規範為準。

## 開始前 10 條

1. **先看狀態，再讓使用者修改。**
2. **密度不靠縮小字體。**
3. **優先使用既有共用骨架與元件。**
4. **共用操作與呈現，不硬統一業務規則。**
5. **小設定行內展開；中型設定用 Settings Panel；大型工作台才獨立頁。**
6. **大量資料先設計搜尋、篩選、排序、批次。**
7. **未儲存內容不得無提示消失。**
8. **錯誤就地顯示，不只丟全頁錯誤。**
9. **桌機與 iPad 都要驗收。**
10. **未取得使用者明確授權，不合併正式站。**

## 四種骨架

- 狀態列型：`名稱｜目前值｜操作`
- 編輯展開型：看狀態 → 修改 → 儲存／取消 → 收合
- 清單管理型：搜尋｜篩選｜清單｜狀態｜操作
- 預設＋例外型：店家預設 → 個別例外 → 批次套用

## 三個核心容器

- Settings Center
- Settings Panel
- Reminder Center

## 新功能開發前四問

- 它屬於哪一種既有骨架？
- 能不能使用現有共用元件？
- 目前狀態是否能一眼看懂？
- 資料變很多時是否仍然好用？

## Preview 最低驗收

- 一眼看懂目前狀態
- 操作入口清楚
- 沒有不必要跳頁
- 未儲存安全
- 大量資料仍可用
- 返回後保留 tab / filter / scroll
- 桌機舒服
- iPad 可操作
- 其他模組是否需要同步
