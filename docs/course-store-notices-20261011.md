# 課程門市共用通知與獨立操作開關

## 範圍

運動／音樂課程。學員自行預約、請假、改期各自設定；門市共用後台通知，店長個人 LINE 通知維持既有選用。沒有建立員工私人 LINE 收件流程。

## 畫面

後台頂欄右側鈴鐺 → 共用 RightSheet → 待處理／已處理。緊湊兩行清單與 ○／O；整列原列展開，處理人與時間收在詳情。支援單筆復原、失敗還原、版本衝突、查看權限與處理權限分離、50 筆分頁。

60 秒更新與返回前景更新，沒有自動搶焦點或跳頁。提示音預設關閉，以裝置／門市保存，需使用者手勢啟用音訊。多台裝置各自選用；不是 WebSocket 即時推播。

## 交易與權限

- 通知於原課程交易內寫入，失敗一起回滾；普通預約為已處理資訊。
- 學員異動待門市處理；店員登記請假／整堂改期／停課仍保留後續確認事項；恢復上課收斂舊待辦。
- O 只更新通知，不改出席、點數、付款、退款或補課。
- 門市看通知需 `booking.read`，處理需 `booking.update`，設定需 `business_hours.manage`；授課請假／改期採獨立教師權限與同店、本人授課連結檢查。
- 固定期課／補課改期沿用門市調課，不解除原有方案限制。音樂學員請假使用現有 STUDENT_LEAVE 規則，團班仍依原規則扣堂。
- 一般學員改期維持一次鎖定交易與付款移轉；同一改期鏈合併為一筆後台通知。

## 資料更新

新增 CourseBookingRule 三個欄位與 CourseStoreNotice。安裝時自行改期沿用舊自行預約值，請假保留原本開放，後台通知預設關閉。RLS 開啟，browser roles 無直接存取。關閉後不收集新通知，既有待辦保留，重開不掃舊課程。

DDL 尚未套到任何遠端資料庫。新支線自動部署已關閉，build preflight 阻止它繼承非隔離資料庫或執行自動 migrations。

## 驗證與界線

- TypeScript 與修改檔 ESLint；獨立開關、門市通知、教師授權與舊課程回歸測試。
- PGlite 本機 PostgreSQL：安裝預設、門市事件唯一性、FK、RLS/browser revoke、交易回滾、處理狀態約束及版本競態。
- 虛構元件瀏覽器：1366×900、1920×1080、1024×768、768×1024、560×800、390×844、360×800；O、復原、失敗還原、原頁草稿保留與水平溢出檢查。
- 本機瀏覽器缺少中文字型，版面互動檢查不代表中文字型視覺驗收完成；真實 iPad／Safari 未驗。
- 隔離 Preview 的登入→server action→真實 PostgreSQL 往返、實際通知事件與多工作階段同步仍待驗；沒有正式合併或正式站部署。

## 異動入口

接入學員新增／請假／取消／改期、原生請假恢復、整堂取消、單堂排課編輯、批次調課、停止後續課程及教師缺席／恢復。整堂事件合併為一筆，展開顯示影響名單；仍需隔離資料庫逐入口驗收。

## 最終本機結果

- 全套 1,014 個測試檔、9,498 項測試通過，16 檔／129 項跳過。Vitest 仍回報一項既有 checkout/copy-button.tsx 的 1.5 秒計時器在 jsdom 拆除後存取 window 的未處理錯誤，因此全套執行退出碼為 1；不可宣稱全套無錯誤。
- 三個部署隔離回歸檔更新 build chain 後個別 69 項通過；修改檔 ESLint、TypeScript 通過。
- GitHub 上傳被自動核准審查拒絕，理由為尚未明確授權發布程式碼至該遠端；只有本機提交，未建立 PR。
