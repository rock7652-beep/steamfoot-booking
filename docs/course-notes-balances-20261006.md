# 課程備註與有效方案合計

- 運動／音樂上課名單直接提供「＋本次備註／編輯本次備註」，使用既有 booking notes 與後端權限；店內備註分開標示。原單方案課後餘額明確標示「本方案課後剩餘」。
- 顧客前台首頁與我的方案顯示全部有效方案總剩餘、已預約、可用；點數與堂數分開，同一共卡只計一次。方案個別效期、課程限制與扣點順序保留。
- 店長顧客方案視窗的合計由授權後查詢計算，獨立於搜尋／歷史／20筆分頁；不在全店清單顯示跨顧客總額，以免重複計共卡。
- 不新增 migration，不改正式顧客餘額。

驗證：5 檔 57 項測試、完整 TypeScript、變更檔 ESLint 與 diff 檢查通過。包含 21 張有效方案、重複共卡、點／堂分離、過期／停用、全數預約／用完、後台分頁仍顯示完整合計。

入口：運動／音樂上課名單、顧客詳情的持有方案、課程會員首頁／我的方案。
