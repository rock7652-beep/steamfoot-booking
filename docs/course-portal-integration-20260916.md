# 課程前台定案版真實串接

## 範圍
- 會員首頁／預約／我的預約／我的分頁；教練今日工作／課表／授課紀錄。
- 真實共卡成員選擇，不預選本人；點數／堂數額度、快到期方案排序及課程適用限制。
- 本人健康紀錄依店家功能開關與會員身分讀取，共卡不開放健康資料。
- 匯款通知、待核帳訂單、店長核帳、啟用方案及非現金收入。交易以店家鎖定，同一訂單重送不重複發卡。
- 教練批次出席／未到／更正，單一交易處理名單，額度與狀態一起更新；保留異動紀錄。
- 店長可設定方案單位與適用課程，以及線上購買匯款資訊。已發卡保留發卡時規則。
