# HQ 導覽收尾（2026-10-03）

## 行為

- HQ 全部分店：首頁／品牌總覽、店舖管理、營運與財務、顧客經營、系統工具。
- HQ 選定單店：蒸足／SPA／課程使用該模組既有導覽，固定提供「返回 HQ 總部」。
- 店舖清單、店舖詳情與功能設定、店舖組織、訂閱及體驗申請是跨店平台管理頁；即使目前選定課程店，也使用 HQ 外框，不受課程頁路由限制。
- 切店成功後進入 `/hq/dashboard`，不沿用上一店的子頁與篩選；裝置預覽 iframe 保留 `devicePreview=1`。
- 返回 HQ 先清除單店查看視角，成功才導頁；失敗保留目前店。
- HQ 的 iPad 768px 起保留側欄，直向預設圖示模式，可手動展開；較小畫面仍有選單抽屜。
- 分組記住使用者明確收合選擇，當前頁所在分組自動展開；訂閱／組織子頁不重複亮起店舖清單。

## 範圍

共用原本的 DashboardLayout、側欄與權限／功能過濾。未新增資料表、遷移、功能授權或角色權限。原 MVP 隱藏路由維持隱藏。店長自己的產業選單內容維持原規則。

裝置預覽工作台仍保留原本滿版外框及「返回後台」入口，內嵌後台保留側欄。

## 盤點證據與限制

測試站 HQ 首頁切蒸足及音樂店可保留側欄，未在該版本重現使用者回報的完全消失。已確認原生 `/hq/dashboard/stores/*`、`/hq/dashboard/trial-applications/*` 沒有 dashboard layout；原 HQ 在切店時仍沿用頁面，缺少明確返回 HQ 的操作；非 SPA 的 iPad 直向側欄原本在 1024px 以下隱藏。

本輪補齊上述導覽連續性缺口，仍需 Preview 的切店→功能頁→返回 HQ，以及桌機、平板橫直向驗收。尚未合併正式站。
