# 登入與操作稽核補齊 — 開發與驗收狀態

分支：feat/hq-login-operation-audit。未合併正式站。

## 本次已實作

- 共用稽核入口：操作、登入兩個分頁；四模組店務管理入口與 HQ 系統工具。
- Email 後台驗證成功／失敗紀錄，未知帳號不臆測身分或門市。
- 不儲存密碼、驗證碼、憑證、原始 IP、原始 User-Agent；裝置只保留概略分類。
- 登入 ID 從伺服器驗證的 session 關聯到操作；不採用輸入的 loginRecordId。
- 舊 JWT 仍維持原有權限驗證，不虛造歷史登入；無關聯會顯示未連結。
- 最近使用時間約每 5 分鐘更新；與登入時間分開。
- 操作者姓名／角色快照；AUTO_ 動作標示系統自動，保留觸發帳號。
- 店家頁面強制本店；HQ 沿用已授權店家視角。個別歷史查詢新增 audit.read guard。
- 寫入及顯示時遮蔽敏感欄位。舊紀錄沒有身分快照時標明是目前身分。
- 支線 Preview 在兩條 DB connection 未確認隔離時，停止遷移。

## 已驗證

- 8 組相關測試、47 個測試通過：登入資料最小化、未知帳號、使用時間限頻、登入關聯、店家範圍、歷史權限、既有工作帳號撤銷、敏感資料遮蔽。
- Prisma 三套 client 生成成功。
- 修改檔案 ESLint 通過，diff whitespace 檢查通過。

## 尚未完成，禁止視為驗收通過

- TypeScript 檢查（6GB heap）通過；最新收尾改動仍由 CI 再確認。
- 真實隔離資料庫遷移、登入成功／失敗、停用人員與 HQ 代操作端到端驗收。
