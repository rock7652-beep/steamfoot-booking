# 課程分頁前台示意 · 2026-09-16

本次新增 public/course-mobile-review/navigation.{html,css,js}，保留原示意及實際功能頁。另外將三個新檔加入既有僅預覽可用的明確檔名清單。所有資料為記憶體假資料，重新整理重置。沒有 API、登入、付款或資料庫寫入。

## 本輪版面

- 手機固定底部圖示＋文字；桌機 900px 以上改為可收合側欄。
- 會員：首頁、預約、我的預約、我的。首頁無月曆；只有預約頁顯示月曆。我的預約分即將上課／歷史，保留同堂合併及逐人取消。
- 教練：今日工作、我的課表、授課紀錄。今日與課表共用原位名單操作。
- 我的：方案、購買、購買紀錄、共卡、健康、個人與店家資訊獨立頁面。
- 健康開通開關同時控制首頁與我的入口，不代表真實權限實作。
- 購買示意：方案 → 確認 → 轉帳回報 → 待店家確認。末四碼不增加可用點數；點數不足引導保留原本上課者選擇。
- 沿用既有示意的報到／完成、占用／取消、失敗保留選擇及重送行為。

## 驗證

JavaScript 語法檢查與 jsdom 互動通過：四／三導覽切換、月曆位置、歷史收合、健康入口開關、購買待確認、A 只替 B 預約、失敗重試、逐人取消、點數不足購買引導。
修復：歷史分頁開啟後新預約成功仍留在歷史，現切回即將上課。

## 明確限制

店家地址／LINE、加入行事曆、真實個人資料編輯與登入綁定未接入；個人與店家頁面僅確認導覽位置，未提供假連結。健康趨勢為文字樣本。銀行資訊為說明，不可真實轉帳。購買方案尚未串接正式交易。
本次不是會員／教練真實功能驗收，不取代原交易與權限測試。等待使用者確認版面後才套入功能頁。不得合併正式站或變動正式資料庫。

補充驗證：Chromium 在 375／390／430／1024px 共 64 個頁面及面板檢查均無水平溢出；瀏覽器假資料流程驗證失敗重試、B 單人代約、取消釋放、報到不扣點、完成一次扣點與固定列序、付款回報不啟用點數。修復部署入口 404：僅新增三個指定靜態檔名，保留正式環境拒絕與其他路徑保護。

## 桌機／手機統整修正版

依最新回饋將動作統一為「出席」「全部出席」「未到」「更正」。出席同時完成方案額度使用，主要按鈕不帶點數／堂數用語。示意另加入堂數方案與混合方案情境；確認面板按各方案顯示使用或退回額度，未到沿用此示意釋放占用規則。更正保留前後狀態、操作人及時間；整批先驗證所有額度才更新，失敗整批不變。

桌機加寬置中、首頁摘要並排、月曆與當日課程左右排列；手機縮短卡片與名單、刪除實作說明和重複收合，已結束課程收合。預約補日期、備註收合、方案分開顯示、授課紀錄月份篩選及更正入口。品牌使用既有正式 Logo 圖檔，導覽改一致線條 SVG。

驗證：64 項 Chromium 頁面寬度檢查（375／390／430／1024px）無水平溢出；互動檢查涵蓋未到改出席、出席恢復待點名、堂數退回、混合方案批次、額度不足整批阻擋、取消者排除、操作紀錄及授課月份篩選。此為假資料示意，尚未套入真實 API、方案與交易；不宣稱堂數真實功能已完成。

## 公休、授課紀錄、滑動與方案適用性回饋

- 月曆依店家公休設定淡化並標示「公休」，未排課不等於公休。此隔離示意設定週日休、9/25 臨休、9/20 特別營業，尚未讀取真實店家設定。
- 授課紀錄：精簡月份前後切換、出席／未到人次、全部／未到／待點名篩選、同頁展開名單與更正。取消者不计入；篩選保留。
- 開啟預約與點名面板時固定背景，內文獨立捲動；重繪保留內文捲動及焦點，關閉還原背景位置。點名通知改浮動提示，不推擠整頁。課程展開收合維持標題位置。
- 預約方案依課程適用清單及上課日有效期限過濾，依到期日排序；預選最早到期且足夠一人使用的方案。額度不足仍顯示原因；無適用方案提供購買引導。瑜珈堂數方案僅適用伸展／瑜珈，肌力不顯示該方案。既有預約綁定不改寫。
- 我的方案與首頁方案摘要採到期順序，課程卡費用依適用方案顯示單位。
- Chromium 在 375／390／430／1024 寬度各跑 19 個互動檢查：公休與特別營業、未排課、方案排序／篩選／過期、紀錄月份／未到篩選、面板背景鎖定與復位、面板內勾選保留位置、出席與更正；全部通過。64 個頁面／視窗寬度檢查無水平溢出。
- 尚未驗證實體 iPhone Safari／App 內建瀏覽器的觸控慣性與鍵盤；不可把 Chromium 驗證視為實機驗收。
- 僅修改 navigation.js/css 與本紀錄；假資料、不寫資料庫、不合併正式站。
