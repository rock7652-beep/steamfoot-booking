# 教師／教練與後台人員介面整合

## 已實作

| 位置 | 調整 |
| --- | --- |
| 人員清單 | 共用姓名、聯絡方式、身分、LINE／通知、操作五欄；姓名開啟編輯，授課與 LINE 狀態直接開對應分頁 |
| 基本資料 | 姓名與狀態優先，電話與聯絡信箱選填；生日、緊急聯絡與既有身分連結收在更多資料 |
| 教師／教練視窗 | 共用基本資料、授課設定、LINE 與權限、課表與時間四分頁；新增後才顯示課表 |
| 後台人員視窗 | 基本資料與後台帳號／權限兩分頁；登入信箱與密碼放後台帳號；薪酬權限集中，其他權限收合 |
| 音樂授課設定 | 課程勾選、預設比例、個別課程薪酬在同一處；保留一般拆帳、彈性拆帳、固定鐘點差異與既有計算規則 |
| 工作權限 | 查看自己薪酬、代學員請假、替學員改期在 LINE 與權限；後端只允許三個明列權限，維持老闆與 HQ 老闆檢視授權 |
| 儲存 | 共用視窗底部儲存，成功仍留在原視窗；可授課時間與基本資料依序確認，失敗保留未儲存草稿；各部分非單一原子交易 |
| 關閉 | 兩模組共用放棄草稿確認；切換分頁不清除輸入 |

後台人員修改與批次啟停限有效老闆角色；授課人員仍遵守既有管理權限。前後端均保留本店、角色、修訂、停用與交接檢查。緊急聯絡已改選填，既有資料保留。
