# HQ 店家實際視角驗收

## 本次範圍

沿用既有店家切換，不新增角色模擬系統。沒有可選的目標角色時，採現有 OWNER 店務能力：保留真實 HQ 登入者、使用者 ID、稽核角色與預約來源，不借用任何店員身分。

- HIDDEN：側欄、手機導覽、頂欄預覽、首頁卡片與捷徑不顯示，也不掛載相關讀取。
- LOCKED：沿用同店 OWNER 的未開通呈現與後端禁止操作。
- 選定店舖後，資料讀寫與匯出限定該店，訂閱限制仍適用。
- 稽核、跨店修復與其他 HQ 專屬工具須先返回 HQ。返回操作不依賴舊店仍有效，舊店停用時提供復原入口。
- 個人歸屬的現金帳修改仍要求真實 Staff 身分；HQ 不假冒店員取得他人個人紀錄的修改能力。

## 重要回歸覆蓋

- 真實 ADMIN 身分不變，店家能力不含 audit.read；返回全部店舖才恢復 HQ 能力。
- 選定 A 店時拒絕 B 店記錄、範圍與匯出參數；不可用自訂 request headers 偽裝路由。
- SPA 預約與資源寫入使用授權的寫入店舖，忽略過期的另一店 cookie。
- 隱藏／鎖定核心預約、顧客與方案功能時，直接 URL／Server Action 仍有守門；核心頁面各自檢查，不依賴可能快取的 layout。
- 人員層級、租金設定、轉介紹及 Messenger 管理保留店內能力邊界。
- 隱藏功能不會在店家首頁產生卡片、數量查詢或空狀態新增捷徑。
