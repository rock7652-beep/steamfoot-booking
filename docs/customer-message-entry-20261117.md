# 顧客訊息入口整合

## 決策與範圍

接續已發布 PR #1581（main f755785857ecc352a4f1166ddd1b937a448827e9）。使用者確認示意：左側不再獨立顯示顧客訊息；顧客管理右上角並列「發送訊息」與「發送紀錄」，顧客詳情提供「發送 LINE」。沿用本次訊息功能發布授權；本次不新增正式對外測試訊息、資料表或排程，也不調整 LINE 停發／隔離保護。

蒸足、運動／音樂、美業管理清單共用入口。可先勾選名單再發送，或未勾選直接進入原本選人流程。單人捷徑只帶入該人；紀錄入口直接顯示紀錄，返回顧客管理回到本店相對模組。原訊息流程及既有網址仍可用。

## 名單與權限

- 入口沿用與發送相同的可寫門市、customer.read、customer.message.send、顧客管理與 LINE 功能檢查。查看模式沒有發送入口；後端仍逐次授權。
- 批次名單只在目前分頁 sessionStorage 暫存 ID、門市及建立時間，URL 只帶隨機參照，不含顧客姓名、電話或 LINE 身分。名單十五分鐘到期，最多五百位，拒絕重複、失效、跨店及格式錯誤。
- 開啟後由後端以當前門市及模組重新解析精確 ID 清單；任何顧客不在當前範圍或已合併就拒絕整批帶入，不默默換人。沒有預覽、排程確認或自動發送的副作用。
- 發送前的既有收件人、額度、權限、門市官方帳號與 retry-key 檢查均保留。新增勾選功能不新增指派、編輯或其他寫入權限。

## 驗證與限制

適用操作情境：02 搜尋與精確名單、05 清單／詳情往返、06 門市與角色隔離、08 RWD、09 功能開通、10 空紀錄／失效名單。交易、多人金額、扣堂與切月情境不適用於這次入口變更，既有訊息整合回歸保留。

合成瀏覽器驗證 1366×900、1024×768、768×1024、390×844：選兩人只帶入兩人、單人捷徑、直接開啟空紀錄、查看模式隱藏入口、無效參照不載入他人資料；沒有觸發預覽或確認外發。證據位於 /tmp/steamfoot-customer-message-entry-qa，這是 component fixture，不是正式店家全模組登入驗收。

最終型別與 ESLint 通過；目前相關十個測試檔九十八項通過，含精確選取、過期／跨店／重複／超量阻擋、撤權，以及既有 LINE 模擬整合、隔離與指南檢查。後台操作指南 LINE-MANUAL-01 同步，不增加指南總題數。

線上 Preview、CI、正式版本與登入驗收結果接續記錄於本次 PR；正式收訊成功證據屬於 PR #1581，不能冒稱為這次入口新一輪外發測試。

發布準備期間 main 已加入 PR #1582（02f81403e8b272af9c1244fe5c6f9534a9d76391）。已整合該課表日期修正；共用 Preview 清單、打包及測試均保留兩項精確分支。首個舊基底 Preview 已取消，最終驗收以整合後版本為準。
