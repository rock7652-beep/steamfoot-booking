# 音樂教室單堂課視窗：參考操作盤點

來源：使用者提供的音教雲固定個別課與單堂團課兩張畫面。此文件記錄畫面可確認的功能；按下後的業務規則需由實際操作錄影確認。目標是先完成單一課次的左學員／右老師工作區，再逐項簡化。

補充：手機截圖 IMG_5906～IMG_5916 顯示同一學員的課次視窗和資料分頁。這些是不同頁面及捲動位置的截圖，不可當成完整按鈕操作錄影。

## 圖中清楚可見的操作

- 固定個別課：左側「取消簽到」「學生繳費」；右側「老師扣薪」。
- 單堂團課：左側「簽到」「曠課」「學生請假」「學生繳費」；右側「老師扣薪」「老師曠課」「老師請假」。
- 兩種課均有學員與老師備註、特殊提醒、近期打卡紀錄。
- 單堂團課顯示「是否扣堂」，固定課顯示「每週」；這是不同課型的規則訊息，不能由畫面文字直接推定蒸管家應如何扣堂、退款或算薪。

手機畫面中的寬表格需橫向捲動，且課次彈窗的學員／老師欄位會在手機上下堆疊。蒸管家可沿用資訊與操作，不應複製這個手機密度；在小螢幕先顯示姓名、電話、狀態與必要操作，其他紀錄點開查看。

## 先複製、再優化的實作界線

1. 先使上述資料與入口集中在一個課次視窗，不讓店長來回切頁。
2. 學員出席、曠課、請假分成不同狀態；請假不得以「取消」冒充。老師出勤與薪資影響分開記錄；「扣薪」不能只當成曠課別名。
3. 所有會改變額度、收費或老師薪資的按鈕，在錄影確認實際規則前只保留功能盤點，不依畫面自行推測並上線。
4. 畫面穩定後再減少不常用欄位、合併重複操作、壓縮密度，維持手機與桌機可捲動。

## 尚需一次操作錄影確認

- 學生請假、曠課和取消簽到各會如何影響課程、剩餘堂數及補課。
- 老師扣薪、曠課、請假各會如何影響授課時數／月結，是否可更正。
- 學生繳費是收單堂學費、收整期，或只記錄當次繳費；退款及作廢入口。
- 固定課與單堂課的備註／特殊提醒是單次生效或延續後續課程。
- 這組十張截圖展示各個資料頁籤，尚未展示請假、曠課、老師扣薪及學生繳費的送出／更正步驟；不要從歷史列表推測按鈕的後端效果。
