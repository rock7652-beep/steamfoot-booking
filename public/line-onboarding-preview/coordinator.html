LINE 開通｜窗口 4 步

指南預覽。操作圖為示範，非實際截圖；開通流程尚待實際演練。

1. 核對店家資料

沿用已提供的店名、店長信箱、官方 LINE 與既有店家紀錄，只補缺漏。確認已有／沒有／不確定其他串接。

完成條件：店名、@ID 與店家確認一致；既有串接已記錄，未知就列待查。

開啟店家版指南 →

2. 用我的個人帳號接受邀請

由窗口目前使用、已向店家確認的個人 LINE 帳號接受 OA 邀請。蒸管家官方 LINE 只作為聯絡窗口。

核對店名、邀請角色與接收帳號後再接受；不以既有總部權限跳過店家授權。

完成條件：店家權限清單出現正確受邀管理員，並留下店家同意範圍。

開啟官方帳號管理 ↗

3. 複製交接單，交給技術端

貼到原工作對話，帶入已知資料與授權結果。邀請連結與憑證不要放進交接單。

查看／手動複製內容

完成條件：技術端能辨識店家、權限、既有串接及核准範圍；未核准項目明列，不當成已同意。

4. 驗收後將入口交付店家

核對本店登入、身分、預約與返回入口；店長取得店家專屬後台，會員／教練取得本店 LIFF。

完成條件：設定、技術檢查及實機驗收各有結果；入口確認可用後才起算試用。未通過的部分不標成已開通。

通知如需外發，先確認指定對象、內容、事件與則數。

補充：必要時才處理 Developers 授權

OA 管理員不等於 Developers 權限。先查現有 channel 的歸屬與角色；若需要編輯 LIFF，再由原管理者授予指定 Login channel 的 Admin。Provider Admin 不作為所有店家的預設要求。

登入信箱從 Console 核對，不假設與個人 LINE 相同。不要求店家重填可由受邀權限取得的資料。

補充：卡住時怎麼處理
  • 邀請失效：確認接收人後請店家重新發行，勿公開邀請連結。
  • 帳號或店名不符：先停止接受，請店家核對。
  • 已有不明串接：先查原服務用途，不覆蓋。
  • 需要設定／資源／外發核准：分開列明，不以交接單當作授權。
