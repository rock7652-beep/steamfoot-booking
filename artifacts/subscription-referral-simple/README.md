## 最短操作

1. 確認朋友開通的店家。
2. 確認首次收款、不同經營者及退款狀態。
3. 符合30天規則後，按一次「確認發放雙方各30天」。只有月繳帳戶需要扣款安排紀錄；年繳與試用不顯示此欄位。

主畫面先顯示待收款／等待30天／可以發放／已發放。已確認的收款表單預設收合，雙方原到期日及新到期日直接呈現，不再分別展開兩個發放表單。測試入口同步縮為三步，其他帳號與申請測試收進次要區塊。
