# LINE 額度 Email 通知畫面驗證

實際 `LineQuotaEmailSetting` 元件與全站 CSS，以 Vite fixture 載入；router、儲存及測試信 actions 為 mock，沒有連線資料庫或寄信。

尺寸：1366×900、1920×1080、1024×768、768×1024、390×844、360×800。每個尺寸檢查長信箱、額度耗盡警示、寄信失敗、修改、縮放保留草稿、儲存及測試信回饋、整頁無水平溢出。截圖包含 editing／saved，結果見 results.json。

共用入口：蒸足提醒管理、運動／音樂課程提醒管理。僅驗證共用元件，未驗實際登入後完整頁面／側欄、真實裝置、Safari、正式寄信與資料庫。不是完整業務驗收或可外寄的 Preview 部署。

程式驗證：12 個相關測試檔、160 項測試通過；TypeScript、受影響檔案 ESLint 及 git diff --check 通過。新增 migration 已於 PGlite 驗證唯一鍵、RLS 與外鍵刪除行為，未套用正式資料庫。

老闆信箱預填調整：owner-default/ 使用未儲存的 OWNER 信箱資料驗證上述六種尺寸。已檢查信箱摘要、預填欄位、尚未儲存時不提供測試信、取消與修改操作、尺寸變化後草稿保留；server action 仍為 mock。老闆信箱相關 action 測試 12 項通過，TypeScript 與受影響檔案 ESLint 通過。

## 現行版本：通知所有老闆

使用者最終決定本店所有有效 OWNER 登入信箱都接收。最新畫面及結果以 all-owners/ 為準；前面的手填／單一老闆預填為開發歷史，非現行操作。

本版於六種尺寸檢查兩位收件人顯示、長信箱換行、無手動信箱欄位、開關草稿保留、儲存與「寄送測試信給所有老闆」。Action／router 仍為 mock，沒有寄出真實郵件。13 個相關測試檔、173 項測試通過，涵蓋多老闆、同地址去重、停用／降級篩選及分別重試；TypeScript 與 ESLint 通過。尚未驗正式站登入及真實資料，不代表已上線。
